## 题目 3

**下列不是 Linux 系统进程类型的是（）**

- A. 交互进程
- B. 批处理进程
- C. 守护进程
- D. 就绪进程 ✅

**正确答案：D**

**解释：**

按照进程的功能和运行的程序分类，进程可划分为两大类：

1. **系统进程**：可以执行内存资源分配和进程切换等管理工作；而且，该进程的运行不受用户的干预，即使是 root 用户也不能干预系统进程的运行。
2. **用户进程**：通过执行用户程序、应用程序或内核之外的系统程序而产生的进程，此类进程可以在用户的控制下运行或关闭。

针对用户进程，又可以分为交互进程、批处理进程和守护进程三类：

1. **交互进程**：由一个 shell 终端启动的进程，在执行过程中，需要与用户进行交互操作，可以运行于前台，也可以运行在后台。
2. **批处理进程**：该进程是一个进程集合，负责按顺序启动其他的进程。
3. **守护进程**：守护进程是一直运行的一种进程，经常在 Linux 系统启动时启动，在系统关闭时终止。它们独立于控制终端并且周期性地执行某种任务或等待处理某些发生的事件。例如 httpd 进程，一直处于运行状态，等待用户的访问。还有经常用的 crond 进程，这个进程类似于 Windows 的计划任务，可以周期性地执行用户设定的某些任务。

## 题目 16

**init 启动进程需要读取（）配置文件**

- A. `/sbin/init`
- B. `/bin/sh`
- C. `/etc/sysvinit`
- D. `/etc/inittab` ✅

**正确答案：D**

> **【体系说明】这是全套题目中最典型的"老体系"题，基于 SysV init（RHEL/CentOS 5、6 时代）。**
>
> **老体系（SysV init）：**
> - PID 1 是 `/sbin/init`，启动时读取 `/etc/inittab`
> - `/etc/inittab` 定义默认运行级别，如 `id:3:initdefault:`
> - 运行级别 0～6：0 关机、1 单用户、3 字符界面、5 图形界面、6 重启
> - 服务脚本放在 `/etc/init.d/`，用 `service xxx start` 操作、`chkconfig` 设置开机自启
>
> **新体系（systemd，CentOS 7 / Ubuntu 15.04 起至今）：**
> - PID 1 是 **systemd**，`/etc/inittab` 已废弃（很多系统上文件还在但不再决定启动行为）
> - 运行级别被 **target** 取代：
>   - `multi-user.target` ≈ 旧运行级别 3（字符界面）
>   - `graphical.target` ≈ 旧运行级别 5（图形界面）
>   - `rescue.target` ≈ 单用户模式，`emergency.target` 为更底层的紧急模式
> - 查看/设置默认启动目标：
>   ```bash
>   systemctl get-default
>   systemctl set-default multi-user.target
>   ```
> - 服务操作统一为 `systemctl start/stop/restart/enable/status xxx`，服务单元为 `xxx.service`
> - 日志统一用 `journalctl` 查看
> - 系统启动速度更快，服务并行启动、按需激活

## 题目 24

**软件项目存储于 /ftproot，允许 apache 用户修改所有程序，设置访问权限的指令是？（）**

- A. `chmod 777 /ftproot` ✅
- B. `chgrp apache /frproot`
- C. `chown apache /ftproot`
- D. `chmod apache /ftproot`

**正确答案：A**

**解释：**

`chown apache /ftproot` 可以把 /ftproot 目录的所有者改成 apache，但是所有者具有什么权限，题目没说。

> **【体系说明】chmod/chown 命令本身至今不变，但题目的场景是 RHEL5 时代的 FTP + Apache。**
> - 现代 Web 服务以 **Nginx** 为主流，Apache（httpd）仍在使用；服务进程账号在 RHEL 系是 `apache`、Debian/Ubuntu 系是 `www-data`
> - 网站根目录通常是 `/var/www/html/`，独立 FTP 场景已少见，多改为 SFTP/部署流水线
> - **实践中答案 A 的 `chmod 777`（所有人可读写执行）是强烈不推荐的做法**，等于放弃权限控制。现在的标准做法是最小权限：`chown` 把目录归属给服务账号或部署账号 → 目录 `755`、文件 `644` → 需要写入的目录再单独授权。题目考的是命令效果，现实中别照搬 777

## 题目 29

**下面有关 bash 配置文件，说法正确的是？（）**

- A. `.bash_logout`：退出 shell 时，要执行的命令 ✅
- B. `.bash_profile`：每个用户都可使用该文件输入专用于自己使用的 shell 信息，当用户登录时，该文件仅仅执行一次；默认情况下…… ✅
- C. `/etc/bash.bashrc`：该文件包含专用于个人的 bash shell 的 bash 信息，当登录时以及每次打开新的 shell 时，该文件被读取
- D. `/etc/profile`：此文件为系统的每个用户设置环境信息，当用户第一次登录时，该文件被执行 ✅

**正确答案：A、B、D**

> **【体系说明】bash 的用户级配置文件（`.bash_profile`、`.bashrc`、`.bash_logout`）机制至今不变，但系统级文件路径要注意发行版差异：**
> - RHEL/CentOS/Rocky：全局 bash 配置是 **`/etc/bashrc`**（不是 `/etc/bash.bashrc`），并由 `/etc/profile` 调用 `/etc/profile.d/*.sh` 目录下的片段——现在自定义全局变量/别名通常往 `/etc/profile.d/` 里放一个 .sh 文件，而不是直接改主文件
> - Debian/Ubuntu：全局文件是 **`/etc/bash.bashrc`**
> - 加载逻辑区分"登录 shell"（读 `.bash_profile` / `.profile`）和"非登录交互式 shell"（读 `.bashrc`），常见做法是在 `.bash_profile` 里 source `.bashrc`，这与当年一致
> - 新增的体系级方式：systemd 用户/服务环境可用 `environment.d`、`/etc/environment` 设置；图形会话的环境变量不再走 bash 配置，这是现代桌面/服务器环境容易踩的坑

# 附：老体系 vs 新体系总览（2018 → 现在）

> 除上面逐题标注的外，再给一张整体对照表。题目中纯命令类（tar、cat、grep、cut、du、chmod、useradd、mount、硬链接、文件描述符等）在当前主流发行版上**语法和答案依然有效**；变化最大的是"服务管理"和"网络/防火墙工具"。

| 类别 | 老体系（RHEL5/6，约 2018 年前） | 新体系（现在主流：RHEL7+/8/9、Ubuntu 16.04+） |
|---|---|---|
| 初始化进程 | SysV init（RHEL）/ 短暂出现过 Upstart（Ubuntu） | **systemd**（PID 1） |
| 默认级别 | `/etc/inittab` 中的 runlevel 0～6 | target：`multi-user.target`、`graphical.target` 等 |
| 服务管理 | `/etc/init.d/xxx`、`service`、`chkconfig` | `systemctl start/enable/status xxx.service` |
| 系统日志 | 文本日志 `/var/log/messages` 等 | **journald**（`journalctl`）+ rsyslog 并存 |
| 定时任务 | crond / crontab | cron 仍可用；新增 **systemd timer** |
| 网络查看 | `ifconfig`、`netstat`、`route`（net-tools） | `ip addr`、`ss`、`ip route`（iproute2） |
| 网络配置 | `network` 服务 + 网卡配置文件 | **NetworkManager**（`nmcli`）或 systemd-networkd（`networkctl`） |
| 防火墙 | iptables 直接写规则 | **firewalld**（`firewall-cmd`）/ **nftables**；底层 iptables 仍可作兼容前端 |
| 软件包（RHEL 系） | `yum` | `dnf`（RHEL 8 起，用法与 yum 基本一致） |
| 软件包（Debian 系） | `apt-get` | `apt`（apt-get 仍可用） |
| 主机名/时间 | 改文件、`setup` 等 | `hostnamectl`、`timedatectl`、`localectl` |
| Web 服务 | Apache（httpd）为主 | Nginx 为主，Apache 仍在；进程账号 apache/www-data |
| 文件传输 | FTP（vsftpd 等） | SFTP/SSH 为主，FTP 已少见 |
| 容器/编排 | 刚兴起（2013 年后） | Docker、containerd、Kubernetes，已成为运维必备技能 |
| 配置管理 | 2018 年 Ansible 已流行 | Ansible 仍是主流，外加 Terraform/云原生体系 |
