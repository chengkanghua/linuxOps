# 安装linux系统对硬盘分区时，必须有哪两个分区？

```bash
第一句（最重要）
CentOS 6 最少需要 2 个分区：/（根分区）和 swap（交换分区）。

第二句
CentOS 7 最少只需要 1 个分区：/（根分区），swap 可选。

第三句（神级加分回答）
生产环境标准分区： /boot + / + swap + /data
针对你刚才的疑问，补充 1 句救命答案
问：CentOS 6 只分一个 / 能装吗？会卡死吗？
答：能装，有警告但能继续，不会卡死，只是没交换分区，内存不够时会变慢。


生产标准分区（永远不会错）
/boot    1G
/        200G
swap     8G（内存>8G）
/data    剩余所有空间

为什么生产环境一定要单独分 /boot？（面试必背）
3 个核心原因：
防止根分区写满，导致系统无法启动
如果 /boot 放在根分区 / 里
根分区满了 → 系统内核无法更新、无法启动
单独分 /boot → 绝对不会被占满
便于系统修复、救援模式使用
符合企业标准化规范

所有服务器统一分区：/boot + / + swap + /data  
#物理内存大于等于64G 时候 swap不分配
```

# 简述RAID0,RAID1,RAID5，三种工作模式的工作原理及特点。

```bash
RAID 0 又称条带化（Striping），它将数据分割成大小相等的数据块，并行地写入到多个磁盘中
例如，有两块磁盘组成的 RAID 0，数据会交替地存储在这两块磁盘上，磁盘 1 存储数据块 1、3、5 等，磁盘 2 存储数据块 2、4、6 等。当读取数据时，多个磁盘同时工作，并行读取各自存储的数据块，再组合成完整的数据。
优点：读写性能极高。
缺点：数据可靠性差
适用数据不重要服务器，数据库从库

RAID 1 即镜像（Mirroring），数据会完整地同时写入到多个磁盘中。2的倍数盘都可以
优点：数据安全性高。
缺点：存储成本高。因为数据完全冗余，实际可用存储空间仅为所有磁盘总容量的一半。
100冗余   适用数据库重要  数据库 监控服务器

RAID 5 采用条带化存储，并在每个条带中加入校验信息。假设由三块磁盘组成 RAID 5，数据以条带形式分布在三块磁盘上，同时生成校验数据，校验数据也分布在这三块磁盘上。 至少3块盘，可以坏一块盘。
优点：兼顾了数据安全性和存储成本。
缺点：写入性能相对 RAID 0 会有一定下降，因为每次写入都需要计算和更新校验数据。
一般企业都可以
```

# 请填写192.168.0.0./22地址段可用地址数量和范围，掩码地址，网络地址，广播地址。

```bash
计算子网掩码：
/22 表示子网掩码中前 22 位是 1，后 10 位是 0。
子网掩码用点分十进制表示为：
前 22 位：11111111.11111111.11111100.00000000
转换为十进制：255.255.252.0

所以，掩码地址是 255.255.252.0。

计算网络地址：
给定网络地址 192.168.0.0，子网掩码为 255.255.252.0。
网络地址是通过将 IP 地址与子网掩码进行按位与运算得到的。
192.168.0.0：11000000.10101000.00000000.00000000
255.255.252.0：11111111.11111111.11111100.00000000
按位与运算结果：11000000.10101000.00000000.00000000，即 192.168.0.0
所以，网络地址是 192.168.0.0。


计算广播地址：
广播地址是该网段中最后一个地址。
已知网络地址是 192.168.0.0，子网掩码 255.255.252.0，意味着主机位有 10 位。
主机位全为 1 时就是广播地址。
网络地址：192.168.0.0（11000000.10101000.00000000.00000000）
广播地址：192.168.3.255（11000000.10101000.00000011.11111111）
所以，广播地址是 192.168.3.255。


计算可用地址数量和范围：
可用地址数量：
主机位数为 10 位，可用地址数量为 210−2（减去网络地址和广播地址）。
210=1024，所以可用地址数量为 1024−2=1022 个。

可用地址范围：
第一个可用地址是网络地址加 1，即 192.168.0.1。
最后一个可用地址是广播地址减 1，即 192.168.3.254。
所以，可用地址范围是 192.168.0.1 - 192.168.3.254。

综上所述：

可用地址数量：1022 个
可用地址范围：192.168.0.1 - 192.168.3.254
掩码地址：255.255.252.0
网络地址：192.168.0.0
广播地址：192.168.3.255
```

# 简述raid0,raid1,raid5,raid0+1的含义

raid10  原理:两个raid1基础上做raid0 最少4块  容量是所有之半  冗余可以损坏一半 读写很快   对于安全和性能都要    高并发和高访问数据库
