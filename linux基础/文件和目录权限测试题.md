# 文件和目录权限测试题

> 本文系统讲解文件/目录权限：chown 修改属主属组、chmod 数字权限法与符号权限法、文件与目录权限的关键区别、Web 服务标准权限，并附两道经典权限测试题。

## 一、修改文件/目录的属主和属组（chown）

```bash
# 1. 仅修改属主（用户）
chown [用户名] [文件/目录]

# 2. 同时修改属主 + 属组（最常用！）
chown [用户名]:[组名] [文件/目录]

# 3. 递归修改（目录 + 目录下所有子文件/子目录）
chown -R [用户名]:[组名] [目录]
# 兼容写法：用户名.组名 和 用户名:组名 效果完全一样
```

**实战示例**
```bash
# 把 a.txt 的属主改成 root
chown root a.txt

# 把 a.txt 的属主改为 www，属组改为 www
chown www:www a.txt

# 递归修改目录（工作最常用）
# 把 /var/www/html 目录及里面所有内容的属主/属组都改为 nginx
chown -R nginx:nginx /var/www/html
```

## 二、修改访问权限（chmod）

### 1. 三个核心概念（基础必看）

**权限针对的 3 类用户（谁能访问？）**
- `u` → user，文件**属主**（所有者）
- `g` → group，文件**属组**（所属组）
- `o` → other，其他用户
- `a` → all，所有用户（u+g+o）

**权限的 3 种类型（能做什么？）**
- `r` → read，读权限
- `w` → write，写权限
- `x` → execute，执行权限

**权限数字对应值（最核心！）**

| 权限 | 符号 | 数字 | 含义 |
| :--- | :--- | :--- | :--- |
| 读 | r | 4 | 查看文件内容 / 浏览目录 |
| 写 | w | 2 | 修改 / 删除文件 / 创建文件 |
| 执行 | x | 1 | 运行脚本 / 进入目录 |

**数字相加 = 最终权限**，例：`rwx = 4+2+1 = 7`，`rw- = 4+2 = 6`，`r-x = 4+1 = 5`。

### 2. 数字权限法（工作首选）

```plain
chmod [3位数字权限] 文件/目录
```
3 位数字分别对应：**属主 (u) + 属组 (g) + 其他 (o)**。

**最常用 5 组权限（背会这 5 个够用 99%）**

| 数字 | 权限 | 适用场景 |
| :--- | :--- | :--- |
| 755 | rwxr-xr-x | **目录默认权限**（可进入、可读取） |
| 644 | rw-r--r-- | **文件默认权限**（可读写、只读） |
| 777 | rwxrwxrwx | 开放所有权限（慎用，仅测试用） |
| 600 | rw------- | 私密文件（仅自己能读写，如密钥） |
| 700 | rwx------ | 私密目录（仅自己能访问） |

```bash
# 1. 给文件设置 644（最常用文件权限）
chmod 644 a.txt

# 2. 给目录设置 755（最常用目录权限）
chmod 755 /data

# 3. 给脚本加执行权限
chmod 755 test.sh

# 高频：递归修改目录及所有子内容权限
chmod -R 755 /www
```

### 3. 符号权限法（灵活用法）

```bash
chmod [用户][+-=][权限] 文件/目录

# + 添加权限；- 移除权限；= 直接赋值权限

# 给属主添加执行权限
chmod u+x test.sh
# 给其他用户移除写权限
chmod o-w a.txt
# 所有用户添加读权限
chmod a+r a.txt
# 直接设置属组为只读
chmod g=r a.txt
```

### 4. 关键区别：文件 vs 目录 的权限含义

新手最容易错，一定要记：

1. **文件**
   - `r`：查看内容
   - `w`：修改 / 删除
   - `x`：**执行脚本 / 程序**
2. **目录**
   - `r`：查看目录里的文件列表
   - `w`：创建 / 删除 / 重命名文件
   - `x`：**进入目录（cd）**

> **目录必须有 x 权限，否则无法进入！**

## 三、Web 服务（Nginx/Tomcat）标准权限

结合 `chown` + `chmod`，一键修复网站权限：

```bash
# 1. 修改归属
chown -R nginx:nginx /usr/share/nginx/html

# 2. 目录权限 755
chmod -R 755 /usr/share/nginx/html

# 3. 文件权限 644
find /usr/share/nginx/html -type f -exec chmod 644 {} \;
```

## 四、权限测试题

### 题目一：老师有一个重要文件，只有班长和课代表可以修改、读取，其他同学不可以读写修改

```bash
# 1. 创建目录
mkdir /book

# 2. 进入目录再建文件（路径正确）
cd /book
touch text1

# 3. 创建两个用户：班长 bz、课代表 kdb
useradd bz
useradd kdb

# 4. 创建专用组 zy
groupadd zy

# 5. 把班长、课代表都加入这个组
gpasswd -M bz,kdb zy

# 6. 给文件设置 属主 bz、属组 zy
chown bz:zy text1

# 7. 文件权限 660 —— 仅属主、属组读写，其他人无权限
chmod 660 text1

# 8. 关键补充：锁定父目录 /book，防止其他同学进入浏览
chown bz:zy /book
chmod 750 /book
```

**权限拆解（为什么这样设）**
- 文件 `text1` 权限 **660**
  - 属主 (bz)：`rw-` 可读、可修改
  - 属组 (zy：bz、kdb)：`rw-` 可读、可修改
  - 其他人：`---` 无权读、无权写、无权进
- 目录 `/book` 权限 **750**
  - 属主：可进入、可查看、可修改目录
  - 属组：可进入、可查看
  - 其他人：完全无法进入 `/book` 目录

### 题目二：你有一个隐私日记本 book，里面有 text1/text2/text3，你有 3 个闺蜜可以修改此文件，其他小伙伴不可修改、不可读

```bash
# 1. 创建目录 + 进入 + 批量创建 3 个文件
mkdir /book
cd /book
touch text{1..3}.txt

# 2. 创建组 + 3 个闺蜜用户 + 加入组
groupadd zy
useradd gm1
useradd gm2
useradd gm3
gpasswd -M gm1,gm2,gm3 zy

# 3. 递归修改 /book 及所有文件的属组为 zy（只改组）
chown -R :zy /book/

# 4. 批量给文件设置 660
# 权限：属主 rw-  |  组内 rw-  |  其他人 ---
# 闺蜜在组里 → 能读能改；其他人 → 无任何权限
chmod 660 /book/*

# 5. 给目录设置 750（核心）
# 目录权限：属主 rwx | 组内 r-x | 其他人 ---
# 作用：其他人根本进不去 /book 目录，彻底隔绝
chmod 750 /book
```

## 五、权限总结（rwx 含义）

**r（读）**
- 针对目录：能够看到目录下的内容，也就是能够 `ls` 查看目录下的内容
- 针对文件：能够看到文件内的内容，也就是能够用 `cat` 查看文件内的内容

**w（写）**
- 针对目录：如果目录有 w 权限，就可以删除目录下的内容
- 针对文件：如果文件有 w 权限，就可以修改文件内的内容；但是目录没有写权限时，文件不能删除

> 备注：当目录有 w 权限，且目录下的文件有 w 权限，这时才能修改并能删除。

**x（执行）**
- 针对目录：能够通过 `cd 目录名` 进入目录；没有 x 权限就不能 `cd` 进去
- 针对文件：当文件是脚本语言或 java/c 等程序时，赋予执行权限才有用途，否则文件的执行权限没有用
