# 文件和目录权限测试题

# 修改文件/目录的属组和用户

```bash
Linux 修改文件 / 目录 属主（用户） + 属组 命令
# 1. 仅修改 属主（用户）
chown [用户名] [文件/目录]
# 2. 同时修改 属主 + 属组（最常用！）
chown [用户名]:[组名] [文件/目录]

# 3. 递归修改（目录 + 目录下所有子文件/子目录）
chown -R [用户名]:[组名] [目录]
# 兼容写法：用户名.组名 和 用户名:组名 效果完全一样


实战示例  
# 把 a.txt 的属主改成 root
chown root a.txt

# 把 a.txt 的属主改为 www，属组改为 www
chown www:www a.txt

递归修改目录（工作最常用）
# 把 /var/www/html 目录及里面所有内容，属主/属组都改为 nginx
chown -R nginx:nginx /var/www/html
```

# 修改文件 / 目录的访问权限

## <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">一、先搞懂 3 个核心概念（基础必看）</font>

### <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">1. 权限针对的 3 类用户（谁能访问？）</font>

<code><font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">u</font></code><font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);"> → user 文件</font>**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">属主</font>**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">（所有者）</font>

<code><font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">g</font></code><font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);"> → group 文件</font>**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">属组</font>**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">（所属组）</font>

<code><font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">o</font></code><font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);"> → other 其他用户</font>

<code><font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">a</font></code><font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);"> → all 所有用户（u+g+o）</font>

### <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">2. 权限的 3 种类型（能做什么？）</font>

<code><font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">r</font></code><font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);"> → read 读权限</font>

<code><font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">w</font></code><font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);"> → write 写权限</font>

<code><font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">x</font></code><font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);"> → execute 执行权限</font>

### <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">3. 权限 </font>**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">数字对应值</font>**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">（最核心！）</font>

| **<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">权限</font>** | **<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">符号</font>** | **<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">数字</font>** | **<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">含义</font>** |
| :--- | :--- | :--- | :--- |
| <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">读</font> | <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">r</font> | <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">4</font> | <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">查看文件内容 / 浏览目录</font> |
| <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">写</font> | <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">w</font> | <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">2</font> | <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">修改 / 删除文件 / 创建文件</font> |
| <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">执行</font> | <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">x</font> | <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">1</font> | <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">运行脚本 / 进入目录</font> |

**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">数字相加 = 最终权限</font>**

<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">例：</font><code><font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">rwx = 4+2+1=7</font></code><font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">，</font><code><font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">rw-=4+2=6</font></code><font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">，</font><code><font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">r-x=4+1=5</font></code>

## 二、🔥 最常用：<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">数字权限法</font>（工作首选）

```plain
chmod [3位数字权限] 文件/目录
```

<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">3 位数字分别对应：</font>**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">属主 (u) + 属组 (g) + 其他 (o)</font>**

### <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">最常用 5 组权限（背会这 5 个够用 99%）</font>

| **<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">数字</font>** | **<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">权限</font>** | **<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">适用场景</font>** |
| :--- | :--- | :--- |
| <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">755</font> | <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">rwxr-xr-x</font> | **<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">目录默认权限</font>**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">（可进入、可读取）</font> |
| <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">644</font> | <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">rw-r--r--</font> | **<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">文件默认权限</font>**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">（可读写、只读）</font> |
| <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">777</font> | <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">rwxrwxrwx</font> | <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">开放所有权限（慎用，仅测试用）</font> |
| <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">600</font> | <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">rw-------</font> | <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">私密文件（仅自己能读写，如密钥）</font> |
| <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">700</font> | <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">rwx------</font> | <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">私密目录（仅自己能访问）</font> |

### <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">实战示例</font>

```bash
# 1. 给文件设置 644（最常用文件权限）
chmod 644 a.txt

# 2. 给目录设置 755（最常用目录权限）
chmod 755 /data

# 3. 给脚本加执行权限
chmod 755 test.sh

高频用法：递归修改权限
给目录 + 目录下所有子文件 / 子目录统一改权限
# 把 /www 目录及所有内容 权限设为 755
chmod -R 755 /www
```

## <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">三、灵活用法：</font>**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">符号权限法</font>**

语法

```bash
chmod [用户][+-=][权限] 文件/目录

+：添加权限
-：移除权限
=：直接赋值权限

实战示例

# 给属主添加执行权限
chmod u+x test.sh

# 给其他用户移除写权限
chmod o-w a.txt

# 所有用户添加读权限
chmod a+r a.txt

# 直接设置属组为只读
chmod g=r a.txt


```

## 四、关键区别：<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">文件 vs 目录 权限含义</font>

<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">新手最容易错，一定要记：</font>

1. **<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">文件</font>**
   * <code><font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">r</font></code><font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">：查看内容</font>
   * <code><font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">w</font></code><font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">：修改 / 删除</font>
   * <code><font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">x</font></code><font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">：</font>**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">执行脚本 / 程序</font>**
2. **<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">目录</font>**

   * <code><font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">x</font></code><font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">：</font>**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">进入目录（cd）</font>**

# <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);"> Web 服务（Nginx/Tomcat）标准权限</font>

<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">结合 </font><code><font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">chown</font></code><font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);"> + </font><code><font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">chmod</font></code><font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">，一键修复网站权限：</font>

```bash
# 1. 修改归属
chown -R nginx:nginx /usr/share/nginx/html

# 2. 目录权限 755
chmod -R 755 /usr/share/nginx/html

# 3. 文件权限 644
find /usr/share/nginx/html -type f -exec chmod 644 {} \;




```

chmod 660 text1

# 8. 关键补充：锁定父目录/book，防止其他同学进入浏览

文件 text1 权限：660

## 二。 你有一个隐私日记本book， 日记本中有N多文件 text1/text2/text3你有3个闺蜜可以修改此文件，其他小伙伴不可修改，不可读。

```bash
# 1. 创建目录 + 进入 + 批量创建3个文件 → 正确
mkdir /book
cd  /book
touch text{1..3}.txt

# 2. 创建组 + 3个闺蜜用户 + 加入组 → 正确
groupadd zy
useradd gm1
useradd gm2
useradd gm3
gpasswd -M gm1,gm2,gm3 zy  

# 3. 递归修改 /book 及所有文件的 属组 为 zy → 正确（只改组，完美）
chown -R :zy /book/   

# 4. 批量给文件设置 660 → 正确！
# 权限：属主rw-  |  组内rw-  |  其他人---
# 闺蜜在组里 → 能读能改；其他人 → 无任何权限
chmod 660 /book/*   

# 5. 给目录设置 750 → 核心正确！
# 目录权限：属主rwx | 组内r-x | 其他人---
# 作用：其他人**根本进不去 /book 目录**，彻底隔绝
chmod 750 /book    
```

权限总结：

rwx

r   针对目录		能够看到目录下的内容， 也就是说能够ls查看目录下的内容

```
针对文件		能够看到文件内的内容，也就是说能够使用cat 查看文件内的内容

```

w  针对目录  如果目录有w权限，就可以删除目录下的内容

```
针对文件	 如果文件有w权限，就可以修改文件内的内容，但是目录没有写权限，文件不能删除。
```

备注： 当目录有w权限，目录下的文件有w权限，这时才能修改并能删除。

```
    x  针对目录	能够通过 cd  目录名 进入到目录里面，如果没有x 权限，就不能通过cd 目录名 进入到目录里面。

针对文件  当文件是脚本语言或java/c等，文件赋予执行权限才有用途，否则文件的执行权限没有用
```
