## 10.已知/tmp 下已经存在 test.txt 文件，如何才能把/mnt/test.txt 直接覆盖掉/tmp/test.txt 而让系
统不提示是否覆盖（root 权限下）（不低于 3 种方法）（6 分题）。

```bash
/bin/cp /mnt/test.txt  /tmp/test.txt 
\cp /mnt/test.txt /tmp/test.txt

unalias cp
cp /mnt/test.txt /tmp/test.txt

\mv -f /mnt/test.txt /tmp
```

# 7、什么是 RAID，描述 RAID0 和 1 的特点。（8 分）
```bash
RAID 是磁盘阵列：把多块独立的物理硬盘，组合成一个逻辑硬盘，
目的是 提升读写速度 或 保证数据安全。

1 RAID0 条带模式
    2 块盘  速度最快 无冗余 坏一块，数据全丢 空间 100% 利用
2 RAID1  镜像模式
    2 块盘 镜像冗余 坏一块，数据完好 空间利用率 50%安全第一

RAID0 追求速度，不怕丢数据；
RAID1 追求安全，浪费空间也不怕。

```

# 8、请描述进程和程序的区别？（5 分）
```bash
程序是静态的代码文件，存放在磁盘中，不占用系统资源；
进程是运行起来的程序，是动态的，占用CPU、内存等资源，有生命周期。
一个程序可以对应多个进程。

1 程序是静态  进程是动态的（进程是程序的执行， 程序是有序代码的集合）
2 进程是暂时的， 程序是永久的 （进程是状态变化的过程， 程序是长久保存的）
3 进程和程序的组成不同  进程组成包括 程序 、数据、进程控制块（进程状态信息）
```
