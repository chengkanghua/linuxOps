#  描述 Linux  系统的启动过程？
```bash
Linux启动流程分为6步：
1. BIOS开机自检；
2. 加载MBR主引导记录；
3. 启动GRUB引导菜单；
4. 加载Linux内核Kernel；
5. 启动系统第一个进程systemd（PID=1）；
6. 系统初始化，启动各项服务，进入登录界面。

```
