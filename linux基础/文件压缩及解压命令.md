# 文件压缩及解压命令

# tar 打包
## 命令说明
打包：把多个文件打包成一个文件，就相当于windows下的把多个文件放到一个大的文件夹里面，打包出来的文件，是原来的文件大小的总和，

压缩：把文件压缩变小，经常配合tar命令使用



## 命令格式
tar [options] 打包后文件    打包前文件

前面相当于一个篮子一样，把后面的东西全部都放到这个篮子里

```bash
命令选项
-c 打包文件，需要配合-f选项使用
-x 解包文件
-v 显示详细过程
-f 指定要操作的文件，必须放在参数的最后面一位，后面必须直接跟文件 
tar -cvf tar_c.tar ./* 
tar -xvf tar_c.tar 

只解压.txt结尾的文档
tar -xvf tar_c.tar *.txt


-C [目的目录] 解包文件到指定的位置
tar -xvf tar_c.tar -C test/



-t 显示打包文件里面的内容，并不解压出来
[root@oldboy_50 tmp]# tar -tvf tar_c.tar 
drwxr-xr-x root/root         0 2018-07-14 19:17 ./1/
drwxr-xr-x root/root         0 2018-07-14 19:17 ./2/
drwxr-xr-x root/root         0 2018-07-14 19:17 ./3/
-rw-r--r-- root/root         0 2018-07-14 19:17 ./4
-rw-r--r-- root/root         0 2018-07-14 19:17 ./5
-rw-r--r-- root/root         0 2018-07-14 19:17 ./6

-r 添加文件到归档压缩的文件包
tar -rvf  tar_c.tar   tar_r.txt  打包后的文件在前面


-z 打包并压缩成gzip格式
tar -zcvf tar_z.tar.gz  1 2 3 4 5 6 


-j 打包并压缩成bzip2格式
tar -cjvf tar_z.tar.bz2  1 2 3 4 5 6 

-p 解压出来的文件还是原来的属性
--exclude 排除特定的文本，支持通配符
tar --exclude "*.txt" -cvf tar_exclude.tar *
tar  -cvf tar_excl.tar * --exclude "*.txt"


-P 不从文件名中删除“/”
我们平常打包文件都不会从“/”下面来进行。如果我们从/下面来进行的话你就会发现他也能打包成功，但是会报一串提示：“：tar: Removing leading `/' from member names”
[root@oldboy_50 tmp]# tar -cvf test.tar /tmp/1.txt 
tar: Removing leading `/' from member names  从成员命中删除“/”
/tmp/1.txt
我们现在不想要这个提示，就可以使用-P选项来实现，但是解压的时候如果不加-P还是会提示从成员中删除“/”
解压的时候如果我们加了-P选项，那个他就按照他打包的那个绝对路径来执行解压

-N：在这个日期（yyyy/mm/dd）后面的文件会被打包进新建的打包里
-h：压缩相对路径的软连接文件
如果压缩的是个文件的相对路径的软连接，加上-h选项，会把源文件的内容复制到链接文件所在的位置，相当于复制了一份过去。打包的是复制后的文件。



```





# gzip 压缩文件（只能压缩文件）
## 命令说明
Gzip用来<font style="background-color:#ffff00;">压缩文件</font>，一般用它压缩的文件都以".gz"结尾。

是在Liunx系统中经常使用的一个对文件进行压缩和解压缩的命令。gzip命令对文本文件有<font style="background-color:#ffff00;">60%~70%</font>的压缩率。gzip只能压缩文件，压缩后的文件会被加上“.gz”后缀，源文件会消失。

减少文件大小的好处：

	1，节省磁盘使用率，

	2，网络传输文件时，减少传输的时间

## 命令格式
gzip [选项] [参数]

## 命令选项
```bash
-d 解开压缩文件，和gunzip的方法一样
[root@oldboy_50 tmp]# gzip -d test_gz.txt.gz 
[root@oldboy_50 tmp]# ls 
test_gz.txt

-l 列出压缩文件的相关信息
[root@oldboy_50 tmp]# gzip -l test_gz.txt.gz 
         compressed        uncompressed   ratio  uncompressed_name
                 32                   0   0.0% test_gz.txt
-n 压缩文件的时候，不保留原始属性
-N 压缩文件的时候保留原始属性
-r 递归处理，将指定目录下的所有文件及其子目录一并处理
递归地传播目录结构。 如果在命令行中指定的任何文件名是目录，gzip将下降到目录并压缩它在那里找到的所有文件。也不是压缩目录，而是压缩目录下的文件。
[root@oldboy_50 tmp]# gzip /tmp/
gzip: /tmp/ is a directory -- ignored
[root@oldboy_50 tmp]# gzip -r /tmp/
[root@oldboy_50 tmp]# tree /tmp/
/tmp/
├── test1
│   └── test2.txt.gz
└── test1.txt.gz
-S 指定后缀名。如果不指定默认的就是“.gz”
[root@oldboy_50 tmp]# gzip test.txt 
[root@oldboy_50 tmp]# ls
test.txt.gz


[root@oldboy_50 tmp]# gzip -S .file test.txt
[root@oldboy_50 tmp]# ls 
test.txt.file

[root@oldboy_50 tmp]# gzip -d -S .file test.txt.file  #解压的指定后缀名
[root@oldboy_50 tmp]# ls 
test.txt

给一个tar并压缩的文件里面追加内容。tar压缩包后缀名写的不规范。
[root@oldboy_50 ~]# tar czvf test.tar.packet /tmp/*      #生成一个不规范名称的压缩包
tar: Removing leading `/' from member names
/tmp/test.txt
[root@oldboy_50 ~]# ls 	
test.tar.packet
[root@oldboy_50 ~]# file test.tar.packet			#查看这个文件的类型 
test.tar.packet: gzip compressed data, from Unix, last modified: Thu Jul 26 10:09:22 2018
[root@oldboy_50 ~]# gzip -d -S .packet test.tar.packet   #指定后缀名使用gzip解压，并不解包
[root@oldboy_50 ~]# ls 
test.tar
[root@oldboy_50 ~]# file test.tar   		#查看解压后的文件类型
test.tar: POSIX tar archive (GNU)

[root@oldboy_50 ~]# touch 1.txt				#创建一个新文件
[root@oldboy_50 ~]# tar -rf test.tar 1.txt 	#把这个新文件追加到刚才的归档文件里面
[root@oldboy_50 ~]# tar tf test.tar   		#查看这个归档包的文件内容
tmp/test.txt
1.txt

```

# zip  压缩
# unzip 解压
## 命令说明
用于解压由zip命令压缩的文件

## 命令格式
unzip [options] [参数]

## 命令选项
```bash
-f 更新现有的文件
-l 显示压缩文件内所包含的文件
-t 检查压缩文件是否正确
-n 解压时不要覆盖原有文件
-o 不询问，直接覆盖文件
-P <密码> 先用zip的密码选项解压
-d 指定要解压到的位置
-x <文件> 不要处理.zip压缩文件中的那些文件



```
