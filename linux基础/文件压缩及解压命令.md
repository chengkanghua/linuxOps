# 文件压缩及解压命令

> 本文讲解 Linux 下最常用的三组压缩/打包命令：`tar`（打包+调用压缩）、`gzip`（压缩文件）、`zip`/`unzip`（跨平台 zip）。

## 一、tar 打包

### 概念：打包 vs 压缩
- **打包**：把多个文件打包成一个文件，相当于 Windows 下把多个文件放进一个大文件夹，打包后的大小约等于原文件大小总和。
- **压缩**：把文件压缩变小，通常与 `tar` 配合使用（`tar` 调用 gzip/bzip2）。

### 命令格式
```bash
tar [options] 打包后文件   打包前文件
```
> 记忆：前面的"打包后文件"相当于一个篮子，把后面的东西全部放进去。

### 常用选项
```bash
-c  打包文件，需配合 -f 使用
-x  解包文件
-v  显示详细过程
-f  指定要操作的文件，必须放在参数最后一位，后面直接跟文件名
-t  显示包内内容，不解压
-r  往归档包里追加文件（打包后的文件写在前面）
-z  打包并用 gzip 压缩（.tar.gz）
-j  打包并用 bzip2 压缩（.tar.bz2）
-p  解压出来的文件保持原来的属性
-C [目录]  解包到指定位置
--exclude  排除特定文件，支持通配符
-P  不从文件名中删除开头的 "/"
-N  只打包指定日期(yyyy/mm/dd)之后修改的文件
-h  打包软链接时，打包其指向的源文件而非链接本身
```

### 实例
```bash
# 打包 / 解包
tar -cvf tar_c.tar ./*                 # 打包当前目录所有文件
tar -xvf tar_c.tar                     # 解包
tar -xvf tar_c.tar *.txt               # 只解压 .txt 结尾的文件
tar -xvf tar_c.tar -C test/            # 解包到 test/ 目录

# 查看包内容（不解压）
tar -tvf tar_c.tar
# drwxr-xr-x root/root 0 2018-07-14 19:17 ./1/
# -rw-r--r-- root/root 0 2018-07-14 19:17 ./4

# 追加文件到包
tar -rvf tar_c.tar tar_r.txt

# 打包并压缩
tar -zcvf tar_z.tar.gz 1 2 3 4 5 6     # gzip 格式
tar -cjvf tar_z.tar.bz2 1 2 3 4 5 6    # bzip2 格式

# 排除特定文件
tar --exclude "*.txt" -cvf tar_exclude.tar *
tar -cvf tar_excl.tar * --exclude "*.txt"
```

### -P 与绝对路径的坑
```bash
# 从 / 下面打包会提示删除开头的 "/"
tar -cvf test.tar /tmp/1.txt
# tar: Removing leading `/' from member names
# /tmp/1.txt

# 加 -P 可保留开头的 "/"（解压时同样需要 -P，否则仍会提示）
```

### -h 与软链接
```bash
# 若压缩的是相对路径的软链接，加 -h 会把源文件内容复制到链接位置，
# 相当于复制了一份过去，打包的是复制后的文件。
```

## 二、gzip 压缩文件（只能压缩文件）

### 说明
`gzip` 用于压缩文件，压缩后的文件通常以 `.gz` 结尾。它是 Linux 常用的压缩/解压缩命令，对文本文件有 **60%~70% 的压缩率**。**gzip 只能压缩文件**（不能压目录），压缩后源文件会消失。

**压缩的好处**：
1. 节省磁盘空间
2. 网络传输时减少传输时间

### 命令格式
```bash
gzip [选项] [参数]
```

### 常用选项
```bash
-d  解开压缩文件（等同 gunzip）
-l  列出压缩文件的相关信息
-n  压缩时不保留原始属性
-N  压缩时保留原始属性
-r  递归处理：压缩目录下的所有文件（注意不是压缩目录本身，而是目录下的文件）
-S  指定后缀名（默认 .gz）
```

### 实例
```bash
# 解压
gzip -d test_gz.txt.gz
ls
# test_gz.txt

# 查看压缩信息
gzip -l test_gz.txt.gz
#   compressed   uncompressed  ratio  uncompressed_name
#          32              0   0.0%  test_gz.txt

# 递归：gzip 不能直接压目录
gzip /tmp/
# gzip: /tmp/ is a directory -- ignored
gzip -r /tmp/
tree /tmp/
# /tmp/
# ├── test1
# │   └── test2.txt.gz
# └── test1.txt.gz

# 指定后缀名（压缩与解压都要指）
gzip test.txt           → test.txt.gz
gzip -S .file test.txt  → test.txt.file
gzip -d -S .file test.txt.file   → test.txt
```

### 实战：给不规范后缀的 tar 压缩包追加内容
```bash
# 生成一个不规范名称的压缩包
tar czvf test.tar.packet /tmp/*
ls
# test.tar.packet
file test.tar.packet
# test.tar.packet: gzip compressed data, from Unix, ...

# 用 gzip 指定后缀名解压（只解压，不解包）
gzip -d -S .packet test.tar.packet
ls
# test.tar
file test.tar
# test.tar: POSIX tar archive (GNU)

# 追加新文件到归档包，再查看
touch 1.txt
tar -rf test.tar 1.txt
tar tf test.tar
# tmp/test.txt
# 1.txt
```

## 三、zip 压缩 / unzip 解压

### 说明
`zip` 用于创建 zip 压缩包（跨平台，Windows 可直接打开）；`unzip` 用于解压由 `zip` 压缩的文件。

### 命令格式
```bash
zip   [选项] 压缩包名 文件/目录
unzip [选项] [参数]
```

### 常用（unzip）选项
```bash
-f  更新现有的文件
-l  显示压缩文件内所包含的文件
-t  检查压缩文件是否正确
-n  解压时不要覆盖原有文件
-o  不询问，直接覆盖文件
-P <密码>  用 zip 的密码选项解压
-d  指定要解压到的位置
-x <文件>  不处理压缩包中的指定文件
```

### zip 基本用法（补充）
```bash
zip -r test.zip /tmp/        # -r 递归压缩目录
zip -q test.zip file.txt     # -q 静默模式，不显示过程
unzip test.zip               # 解压到当前目录
unzip -l test.zip            # 只看内容不解压
unzip -d /opt test.zip       # 解压到 /opt
unzip -o test.zip            # 直接覆盖不询问
```

> **三者怎么选**
> - Linux 之间传递、要保留权限/软链接 → `tar`（配合 `-z`/`-j`）
> - 只需压缩单个文件、追求速度 → `gzip`
> - 要与 Windows 交互 → `zip` / `unzip`
