## 1.文件测试

> \[ -e dir|file ] 存在则为真
>
> \[ -d dir ] 目录是否存在
>
> \[ -f file ] 文件是否存在 
>
> \[ -r file ] 文件是否有读权限
>
> \[ -x file ] 文件是否有执行权限
>
> \[ -w file ] 文件是否有写权限

1.常见使用方式

```plain
[ ! -d /bbb ] && mkdir /test 
[ -d /bbb ] || mkdir /test
```

2.备份`mysql`，手动输入你需要备份的库名称

```plain
read -p "请输入需要备份的库名称: " dumpdb
mysqldump -uroot -pBgx123.com -B $dumpdb > /backup/$(date +%F)_db.sql
```

3.备份`mysql`，无需手动输入需要备份的库名

```plain
#!/usr/bin/bash
User=root
Pass=Bgx123.com
Data=bgxdb
Back_dir=/backup
Date=$(date +%F)
Backup_Path=$Back_dir/$Date
test -d $Backup_Path || mkdir -p $Backup_Path
if [ $? -eq 0 ];then
    echo "=======备份开始======="
    mysqldump -u$User -p$Pass -B$Data >$Backup_Path/mysql_db.sql
    if [ $? -eq 0];then
    echo "=======备份结束======="
    fi
fi
```

> \[ 1 -lt 10 ] 小于

> \[ 1 -ne 10 ] 不等于

> \[ 1 -le 10 ] 小于等于

*1.查看磁盘/当前使用状态，如果使用率超过80%则报警发邮件*

```plain
//怎么看磁盘使用率，怎么获取对应的值

//怎么进行数值比对
if [ $Disk_Free -ge 30 ];then
        echo "Disk Is Use:${Disk_Free}%" > /tmp/disk_use.txt
```

*2.查看内存/当前使用状态，如果使用率超过80%则报警发邮件*

## 3.字符串比较

*1.字符串比对*

```plain
[root@bgx]# [ "$USER " = "root" ];echo $? 
0
[root@bgx]# BBB="" 
[root@bgx]# echo ${#BBB} 
0
#字符长度为 0
[root@bgx]# [ -z "$BBB" ] 
[root@bgx]# echo $?
0 
#字符长度不为 0
[root@bgx]# [ -n "$BBB" ] 
[root@bgx]# echo $?
1
#小结：变量为空 或未定义: 长度都为0
```

*2.字符串比对,必须使用双引号*

```plain
[root@bgx]# [ "$USER" = "root" ];echo $? 
0 
[root@bgx]# [ "$USER" = "bgx" ];echo $? 
1 
[root@bgx]# [ "$USER" != "alice" ];echo $? 
0
```

*3.多整数比对条件*

```plain
[root@bgx]# [ 1 -lt 2 -a 5 -gt 10 ];echo $?
1
[root@bgx]# [ 1 -lt 2 -o 5 -gt 10 ];echo $?
0
#正则比对会使用到[[]]
[root@bgx]# [[ 1 -lt 2 && 5 -gt 10 ]];echo $?
1
[root@bgx]# [[ 1 -lt 2 || 5 -gt 10 ]];echo $?
0
```

*4.正则比对*

```plain
# 单括号无法使用正则语法
[root@bgx]# [ "$USER" =~ ^r ];echo $?
bash: [: =~: binary operator expected 
2
# 双[]才可以使用正则匹配
[root@bgx]# [[ "$USER" =~ ^r ]];echo $? 
0
# 判断变量是不是数字
[root@bgx]# num=123
[root@bgx]# [[ "$num" =~ ^[0-9]+$ ]];echo $?
0
[root@bgx]# num=123a
[root@bgx]# [[ "$num" =~ ^[0-9]+$ ]];echo $?
1
```

6.批量创建用户脚本, 仅个人使用

```plain
#!/usr/bin/bash
read -p "Please input number: " num
read -p "Please input prefix: " prefix
for i in `seq $num`;do
    user=$prefix$i
    useradd $user
    echo "123" |passwd --stdin $user &>/dev/null
    if [ $? -eq 0 ];then
        echo "$user is created."
    fi
done
```
