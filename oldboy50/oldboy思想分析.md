# 老男孩思想分析：学习方法、工作能力与职业素养

> **一篇讲透老男孩教育的"学习观"与"职场观"**：怎么学（记忆七步法、记与忆、思维导图）、怎么讲（演讲四步法）、怎么做（职场价值与做事规矩）。
>
> 笔记原始整理：**薛晓俊**，本文在其基础上做了结构化梳理与扩展。

---

## 一、四大根基：学习能力、学习方法、素养、基础知识

老男孩把一个人的成长拆成四块，缺一块都会塌：

| 根基 | 含义 | 为什么重要 |
| --- | --- | --- |
| **学习能力** | 遇到新东西能不能自己啃下来 | 技术永远学不完，能力是"元能力" |
| **学习方法** | 用什么样的路径去学 | 方法错了，努力就是浪费 |
| **素养** | 职业态度、做人做事的习惯 | 决定你能走多远、别人愿不愿意带你 |
| **基础知识** | 底层原理与基本功 | 决定你的天花板，上层应用都在它之上 |

> **技术是量的提升，思想的提升才是质的飞跃。**
>
> 四块里，**学习方法**是被反复强调两次的那块 —— 因为它是唯一能同时放大另外三块的东西。

---

## 二、大脑的工作机制：把知识从左脑"搬"进右脑

了解大脑的工作机制，是选对学习方法的前提：

| 左脑 | 右脑 |
| --- | --- |
| 逻辑、计算、语言 | 图形化、艺术、空间 |
| **短期记忆**（容易忘） | **长期记忆**（记得牢） |
| 学的时候主要在用左脑 | 真正掌握，要落到右脑 |

**结论**：学习的时候，知识点是先"暂存"在左脑里的；我们要做的，是把它**搬运到右脑**，变成长期记忆。

那么，怎么搬？

---

## 三、如何把知识放进右脑：记忆七步法

这是老男孩学习法的核心，七步一个都不能省：

| 步骤 | 动作 | Linux 运维示例 |
| --- | --- | --- |
| **1. 看一遍** | 眼睛看，建立第一印象 | 看老师演示一遍 Nginx 反向代理 |
| **2. 听一遍** | 听讲解，补上自己看不出的细节 | 听老师讲 `proxy_pass` 后面带不带 `/` 的区别 |
| **3. 想一遍** | 勤思考，问"为什么是这样" | 想清楚请求是怎么流转的、为什么这样转发 |
| **4. 写一遍** | 动手记，输出成笔记 | 把配置片段和原理写进自己的笔记 |
| **5. 说一遍** | 讨论，跟同学碰撞 | 跟同学争论 `root` 和 `alias` 的区别 |
| **6. 用一遍** | 操作一遍，真刀真枪跑起来 | 自己从头搭一遍，报错自己排 |
| **7. 讲一遍** | 讲给别人听 | 把整套架构讲给同学听，让他听明白 |

> **输出才是最好的输入。** 只停留在"看"和"听"，知识永远是老师的；走到"用"和"讲"，才是自己的。

## 四、"记"与"忆"：输入与输出的闭环

### 4.1 记 —— 输入的过程

- 记是**最大化地输入**：上课要带着套路、有结构地去记，而不是抄流水账；
- **进入状态**：什么样的场合就做什么样的事情，上课就全身心上课；
- 下课后第一时间把学习内容、知识重点**总结出来**。

### 4.2 忆 —— 输出的过程

- 忆是**回忆、是想**，这属于输出；
- 每天晚上睡前，把当天学的东西在脑子里**过一遍、说一遍**；
- **想不出来的地方，回去翻，然后继续循环** —— 想不出来恰恰说明那里没真会；
- 早上醒来起床后，把**一天的学习计划**安排好。

```
白天：记（输入）  →  晚上：忆（输出/回忆）  →  想不出来 → 回去补 → 再忆
                                                              ↑
早上：计划今天  ←──────────────────────────────────────────────┘
```

> **你们知道，我做到了 —— "知道"到"做到"之间，还有很远的距离。**
>
> 听课听懂了只是"知道"，能独立做出来、讲出来，才叫"做到"。

## 五、演讲能力提升四步法：做 → 写 → 想 → 讲

演讲不是天赋，是可以练出来的流程。老男孩给出四个动作：

### 第一步：做出来

先把要讲的东西**自己做一遍**，讲的是自己真实做过的**经历**。没做过的东西讲出来是虚的。

### 第二步：写出来

把做过的事情**写出来**：总结、复盘、提炼经验。写的过程会逼你理清楚逻辑。

### 第三步：想出来

在脑子里把它**想出来**，形成一套**思维定势（套路）**：

- 像高手下棋，开局前脑子里已经有前 20 步；
- 大脑容量太大、信息太多，所以要**建立索引、讲求次序** —— 按架构、按顺序去说，而不是想到哪说到哪。

### 第四步：讲出来

- 先**讲给自己听**，在自讲的过程中发现自己的问题；
- 再讲给大家听。

> **输出才是最好的输入。** 讲一遍，胜过看十遍。

## 六、学习的"五到"：眼睛看、勤思考、讨论、操作一遍、讲一遍

| 动作 | 对应的能力 | 说明 |
| --- | --- | --- |
| **眼睛看** | 观察 | 看别人怎么做、看现象和报错 |
| **勤思考** | 理解 | 多问一个"为什么" |
| **讨论** | 碰撞 | 说出来才知道自己哪里是糊的 |
| **操作一遍** | 实践 | 看懂不等于会做 |
| **讲一遍** | 内化 | 能让别人听懂，才是真懂 |

## 七、学习中具体该怎么做（课后闭环）

1. **课后总结要总结好**，不要遗落知识点；
2. **有问题先自己想**：自己想不明白再去找其他途径解决；**不要第一时间就找老师要答案**，把老师作为最后一个解决办法；
3. **学会画图**：把知识点用**思维导图**的方式总结出来；
4. **复习时讲给别人听**，目标是让别人能够听明白；
5. **每天晚上的语音分享要坚持做**，把脑子里的知识点拿出来讲 —— 但**不要死记硬背**，要讲自己的理解。

## 八、职场篇（一）：与统招本科毕业生的差距，怎么追？

### 8.1 差距客观存在

相较于统招本科生，我们在**起跑线**上确实是落后的 —— 最直观的就是**学历**。

除了学历，本科生相对我们的优势主要在于两点：

- **学习能力**
- **学习方法**

### 8.2 如何拉近差距甚至超越

| 对策 | 具体做法 |
| --- | --- |
| **第一：补学历** | 通过**函授/成人教育**提升学历，让学历不再成为工作的拦路虎（先把门槛迈过去） |
| **第二：强能力** | 提高自己的**学习能力**，优化自己的**学习方法**，用效率换时间 |
| **第三：勤总结** | 多总结学习中遇到的各种问题，从中找到适合自己的好方法 |

## 九、职场篇（二）：如何做一个有价值的员工

拿到 offer、开始实习/工作以后，该怎么做？

### 9.1 工作态度

- 做一名合格的运维人员，同时也做一个**有素质的人**；
- 刚工作不知道该做什么，就**主动去问你的老大**："我现在该做些什么？"；
- 如果领导暂时没有安排，**自己也要学**：去了解公司的**服务器架构**与服务器上的**各种配置**；
- **了解你的服务器，你才能更好地工作。**

### 9.2 工作中如何表现自己

- 要有一个目标 —— 一个通往成功的目标，那就是**努力**；
- **老板在的时候要努力工作，老板不在的时候要更努力地工作**，因为你不知道老板什么时候会回来；
- 工作中碰到问题、有更多的工作要做，**不要抗拒** —— 这些能让你多做一点的事，恰恰是**提升你价值**的东西。

### 9.3 如何提升自己的演讲能力

回到第五章的四步法：**做出来 → 写出来 → 想出来 → 讲出来**，循环往复。

## 十、职场做事的硬规矩（补充完善）

老男孩零散提到的几条，整理成日常可执行的规矩：

### 10.1 给领导出方案，至少 3 种

不要只抛一个问题给领导，要带着方案去。建议每个方案都包含：**怎么做、成本/周期、风险、回滚方式**，并**给出你的推荐项**。

### 10.2 服务器提前做压力测试

任何上线、变更、扩容之前，**先压测**：评估容量水位、找出瓶颈点、准备好**回滚预案**。别等线上崩了再去学。

### 10.3 计划好明天的事情

每天结束前，把**明天要做的事**列出来并排好优先级；早上起来直接执行，不用再花时间想"今天干啥"。

## 总结（核心记忆点）

1. **四大根基**：学习能力、学习方法、素养、基础知识 —— 其中学习方法是放大器。
2. **学习机制**：知识先进左脑（短期），要靠方法搬进右脑（长期）。
3. **记忆七步法**：看、听、想、写、说、用、讲 —— 越往后越主动，效果越好。
4. **记与忆**：白天记（输入），睡前忆（输出），想不出来就回去补，早起做计划。
5. **演讲四步法**：做出来 → 写出来 → 想出来 → 讲出来；**输出才是最好的输入**。
6. **学习五到**：眼看、思考、讨论、操作、讲解。
7. **遇问题先自己想**，老师/百度是第二手段，他人是最后手段 —— 先自己解决。
8. **画图与思维导图**：把知识结构化、建索引、有次序。
9. **职场差距**：学历是门槛，靠函授补；学习能力与方法才是超越的本钱。
10. **职场价值**：主动问活儿、主动学架构、**老板不在时更努力**、不抗拒额外的活儿。
11. **职场规矩**：出方案至少 3 种；上线前先压测；每天计划明天的事。
12. **终极提醒**：**知道 ≠ 做到**，中间隔着"做一遍、用一遍、讲一遍"。

## 扩展

### 扩展一：记忆七步法背后的科学依据

老男孩的七步法，和现代学习科学高度吻合：

| 老男孩的说法 | 学习科学的对应理论 |
| --- | --- |
| 忆（晚上回忆一遍） | **主动回忆（Active Recall）**：检索比重复阅读有效得多 |
| 每天回忆、循环 | **间隔重复（Spaced Repetition）**：对抗遗忘曲线的最有效手段 |
| 用一遍 | **在真实场景中练习（Practice Testing）** |
| 讲一遍 | **费曼学习法**：能讲明白才是真懂 |
| 写一遍、画图 | **生成效应 + 双重编码**：文字 + 图像双通道编码，记得更牢 |

### 扩展二：为什么"忆"最重要 —— 艾宾浩斯遗忘曲线

艾宾浩斯实验表明：学完 20 分钟后遗忘约 42%，1 天后遗忘约 67%，1 周后遗忘约 75%。

所以老男孩强调的"**每天晚上睡前过一遍**"，本质就是在遗忘曲线的拐点上做**低成本抢救**：

- 睡前 5 分钟回忆 → 睡眠中大脑自动巩固 → 第二天留存率大幅提高；
- 想不出来的点，就是你的**知识漏洞**，回去补，比盲目重学十遍都有效。

> 一句话：**不复习的学习 = 往漏水的桶里倒水。**

### 扩展三：费曼学习法 = 老男孩的"讲一遍"

费曼学习法四步，与本文方法几乎完全一致：

1. 选一个概念 → 对应"看/听"；
2. **把它讲给一个外行听** → 对应"讲一遍"；
3. 卡住的地方回去补课 → 对应"想不出来就回去看，再循环"；
4. 简化并类比 → 对应"写一遍、画图、建索引"。

**"能让别人听明白"，就是检验是否真懂的唯一标准。**

### 扩展四：思维导图为什么有效

- **符合右脑的图形化偏好**：一张图胜过千字的线性笔记；
- **建立索引**：大脑不擅长线性检索，但擅长"挂在树上"检索；
- **体现次序与结构**：先主干后分支，正好对应"思维定势 / 套路 / 前 20 步"。

建议每个知识点都画一张图：如「Linux 启动流程」「HTTP 请求全流程」「Nginx + PHP + MySQL 调用链」。

### 扩展五：把这套方法用到 Linux 运维学习上（动作清单）

| 阶段 | 动作 | 自检标准 |
| --- | --- | --- |
| 课前 | 预习，列出问题清单 | 带着 3 个问题去听课 |
| 课中 | 记（有套路地记），不抄流水账 | 笔记里能看出结构，不是逐字稿 |
| 课后 | 立刻总结 + 画思维导图 | 一小时内能凭图复述 |
| 实操 | 从头搭一遍，不复制粘贴 | 报错能自己定位并解决 |
| 晚间 | 语音分享 / 讲给同学听 | 同学能听明白 |
| 睡前 | 回忆一遍，想不出回去补 | 能默写出今天的 3 个关键点 |
| 早起 | 计划当天的学习任务 | 有明确的待办清单 |
| 周/月 | 复盘，把零散笔记整理成体系 | 能画出本阶段的知识全景图 |

### 扩展六：职场价值的公式

老男孩讲的"如何表现自己"，可以量化成一个公式：

```
你的价值 = 解决问题的能力 × 可见度 × 可靠性
```

- **解决问题的能力**：靠"学习能力 + 学习方法 + 基础知识"；
- **可见度**：靠"演讲能力 + 主动汇报 + 讲一遍" —— 做得好还要让人知道；
- **可靠性**：靠"老板不在时更努力 + 凡事有方案 + 上线前压测" —— 交给你的事不掉链子。

> 只会干活不会表达，价值会被严重低估；只会表达不会干活，价值撑不过试用期。

### 扩展七：给领导出方案的推荐模板

```
问题/需求：一句话说清现状与痛点

方案 A（推荐）：做法 / 成本与周期 / 风险 / 回滚方式 / 为什么推荐
方案 B（保守）：同上 / 与 A 的区别
方案 C（激进/长期）：同上 / 与 A 的区别

我的建议：选 A，理由……
需要领导决策的点：……
```

### 扩展八：从"知道"到"做到"，中间有三道坎

老男孩说"**你们知道，我做到了 —— 知道到做到很遥远**"，这三道坎分别是：

1. **信息坎**：你以为懂了，其实只记住了结论（过不了"为什么"这一关）；
2. **动手坎**：看懂了但做不出来（缺"操作一遍"）；
3. **迁移坎**：照着能做，换个环境就不会（缺"想一遍 + 讲一遍"，没有形成思维定势）。

**跨过去的方法只有一个：做出来 → 写出来 → 想出来 → 讲出来，反复循环。**
