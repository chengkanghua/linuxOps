# 一、二进制与文字

## 1.1 bit 和字节

计算机底层只有电路的"通 / 断"两种状态，用 `1` 和 `0` 表示：

- 一个 `0` 或 `1` 称为一个 **bit（比特）**；
- **8 个 bit = 1 个 Byte（字节）**，即 `11010001`；
- 一个字节最多能表示 2⁸ = **256** 种不同状态。

容量单位换算：

```
8 bit   = 1 Byte（字节，B）
1024 B  = 1 KB
1024 KB = 1 MB
1024 MB = 1 GB
1024 GB = 1 TB
```

## 1.2 为什么需要字符编码

计算机只存数字，要让屏幕显示字母、汉字，就需要一张"对照表"：**文字 ↔ 数字**。

- 给文字分配编号的规则，就叫**字符编码**。
- 编号 → 二进制存进硬盘；读取时按同样的规则把二进制还原成文字。

> 一句话记住乱码的根源：**用什么编码存的，就必须用什么编码读。** 存读编码不一致，就会出现乱码。

# 二、字符编码的发展

## 2.1 各国各自编码

| 编码 | 适用 | 占用 |
| --- | --- | --- |
| ASCII | 英文、数字、常用符号 | 1 字节，只支持英文 |
| GB2312 / GBK | 中文（GBK 是 GB2312 升级版，2 万多汉字） | 2 字节 |
| Shift-JIS | 日文 | — |
| ks_c_5601-1987 | 韩文 | — |
| TIS-620 | 泰文 | — |

问题：每种编码只照顾本国文字，互相不认识。一个中文文件拿到日文电脑上打开，就是乱码。

## 2.2 Unicode：万国码

为解决互通问题，出现了 **Unicode（统一码）**：给世界上每一种语言的每一个字符分配一个**全球唯一**的编号。

- 目前已收录十几万个字符，还在不断扩充。
- 所有系统、编程语言都支持 Unicode。

但 Unicode 只管"字符对应什么编号"，如果每个字符都固定用较多字节存储，英文内容会浪费大量空间。

## 2.3 UTF-8：最常用的实现

**UTF-8 是 Unicode 的一种具体存储/传输方案**，它按需使用 1～4 个字节：

| 内容 | 占用字节 |
| --- | --- |
| 英文、ASCII 字符 | 1 字节 |
| 欧洲语言 | 2 字节 |
| 中文等东亚文字 | 3 字节 |
| 特殊字符 | 4 字节 |

这样英文不浪费，中文也能表示，所以 **UTF-8 是今天互联网和编程的事实标准**。

小结：

- **Windows 中文版**默认编码是 GBK；
- **Mac / Linux** 默认编码是 UTF-8；
- **Python 3** 源码文件默认 UTF-8，程序里的字符串是 Unicode。

## 2.4 Python 3 中的 str 与 bytes

Python 3 明确区分两种类型：

| 类型 | 含义 |
| --- | --- |
| `str` | Unicode 字符串，给人看的文字 |
| `bytes` | 字节，二进制数据，用于存储和网络传输 |

两者之间的转换：

```python
s = "路飞"                      # str
b = s.encode("utf-8")           # 文字 → 字节（编码）
print(b)                        # b'\xe8\xb7\xaf\xe9\xa3\x9e'

s2 = b.decode("utf-8")          # 字节 → 文字（解码）
print(s2)                       # 路飞
```

图示：

```
        encode() 编码
 str(Unicode) ──────────────▶ bytes(字节)
  "路飞"                        b'\xe8\xb7\xaf...'
        ◀──────────────
        decode() 解码
```

读文件、网络收到的数据通常是 bytes，要显示中文就得 `decode`；写文件、发网络数据前要先 `encode`。**编码问题 99% 是 str / bytes 没分清，或 encode/decode 用的编码不一致。**

> Python 2 时代默认 ASCII、字符串和 bytes 混在一起，坑很多，已随 Python 2 淘汰，不用再记。

## 2.5 常见编码报错排查思路

出现乱码或 `UnicodeDecodeError` 时，依次检查：

1. 数据**原本是用什么编码存的**（文件 / 接口返回）？
2. Python 源文件保存时是不是 UTF-8？
3. 终端（SSH 客户端、Windows cmd）用的什么编码？
4. 操作系统的语言设置？

不确定字节是什么编码时，可借助第三方库 `chardet`（`pip install chardet`）自动猜测，但它只是"猜"，最可靠的还是和数据提供方确认。

# 三、进制与转换

## 3.1 四种常用进制

| 进制 | 使用的数字 | 示例 |
| --- | --- | --- |
| 二进制 | 0、1 | `1010` |
| 八进制 | 0～7 | `12` |
| 十进制 | 0～9 | `10` |
| 十六进制 | 0～9、A～F | `A` |

Python 提供的转换函数：

```python
>>> bin(10)      # 转二进制
'0b1010'
>>> oct(10)      # 转八进制
'0o12'
>>> hex(10)      # 转十六进制
'0xa'
>>> hex(255)
'0xff'
>>> int('1010', 2)   # 按指定进制转回十进制
10
```

## 3.2 二进制 ↔ 十六进制

关系：**4 位二进制 = 1 位十六进制**（因为 2⁴ = 16）。

对照表：

| 二进制 | 十六进制 | 二进制 | 十六进制 |
| --- | --- | --- | --- |
| 0000 | 0 | 1000 | 8 |
| 0001 | 1 | 1001 | 9 |
| 0010 | 2 | 1010 | A |
| 0011 | 3 | 1011 | B |
| 0100 | 4 | 1100 | C |
| 0101 | 5 | 1101 | D |
| 0110 | 6 | 1110 | E |
| 0111 | 7 | 1111 | F |

转换方法：

- **二 → 十六："取四合一"**。以小数点为界，向左/右每 4 位分一组，不足 4 位补 0，每组对照上表换成 1 位十六进制数。
- **十六 → 二："一位拆四位"**。每位十六进制数直接展开成 4 位二进制。

例：`11010110` → 分组 `1101 0110` → `D` 和 `6` → **`0xD6`**。

## 3.3 为什么常用十六进制

- 1 位十六进制正好对应 4 位二进制，1 个字节能用 2 个十六进制字符（如 `0xFF`）表示，**简短好读**；
- 网络抓包、底层数据、内存地址、HTML 颜色值（如 `#FF8800`）都用十六进制表达。

运维看抓包、看硬件寄存器数据时，十六进制几乎是默认语言。

# 四、浮点数与精度问题

## 4.1 整数与浮点数

- 整数（int）：没有小数点；
- 浮点数（float）：带小数点，如 `3.14`。

科学计数法：特别大或特别小的数可以用 `e` 表示，`1.5e3` 就是 1.5 × 10³ = 1500。

```python
>>> 1.5e3
1500.0
```

复数（用得极少）形如 `3 + 5j`，Python 直接支持，了解即可。

## 4.2 浮点精度问题

**整数运算永远精确，浮点数运算可能有微小误差。**

```python
>>> 0.1 + 0.2
0.30000000000000004
```

这不是 Python 的 bug，而是浮点数在计算机里用二进制存储时，0.1 这类数无法精确表示，几乎所有编程语言都一样。

日常处理办法：

- 判断两个浮点数是否相等时，不直接用 `==`，而是判断差值是否足够小；
- 涉及金额等要求精确的场景，用整数存"分"，或使用标准库 `decimal`。

# 五、列表（list）

**一个变量怎么存公司所有员工的名字？** 用列表。

列表是一个**有序的数据集合**，里面可以放任意类型的数据，可以方便地增、删、改、查。

## 5.1 创建列表

```python
L1 = []                          # 空列表
L2 = ['a', 'b', 'c', 'd']        # 4 个元素，索引 0~3
L3 = ['abc', ['def', 'ghi']]     # 列表可以嵌套
L4 = list()                      # 另一种创建空列表的方式
```

## 5.2 查询：索引与切片

```python
>>> names = ['Alex', 'Jack', 'Rain', 'Mack', 'Rachel']
>>> names[0]       # 从 0 开始取第一个
'Alex'
>>> names[-1]      # 负数表示从右往左数
'Rachel'
>>> names[1:3]     # 切片：取索引 1 到 2（含头不含尾）
['Jack', 'Rain']
>>> names[:2]      # 从开头取到索引 1
['Alex', 'Jack']
>>> names[3:]      # 从索引 3 取到末尾
['Mack', 'Rachel']
>>> names[::2]     # 步长 2：隔一个取一个
['Alex', 'Rain', 'Rachel']
```

其他查询方法：

```python
>>> names.index('Rain')    # 返回元素的索引（找不到会报错）
2
>>> names.count('Alex')    # 统计出现次数
1
>>> len(names)             # 列表长度
5
```

## 5.3 增加元素

```python
names.append('Tom')          # 追加到末尾
names.insert(2, 'Lucy')      # 插到索引 2 的位置
names.extend(['A', 'B'])     # 把另一个列表的元素逐个并进来
```

## 5.4 修改元素

```python
names[0] = 'Alexander'       # 直接给某个索引赋新值
```

## 5.5 删除元素

```python
names.remove('Jack')         # 按值删除（删第一个匹配的）
names.pop()                  # 删除末尾元素并返回它
names.pop(0)                 # 删除指定索引
del names[1]                 # 也可以用 del 删指定索引
```

## 5.6 排序与反转

```python
nums = [3, 1, 4, 2]
nums.sort()                  # 原地升序排序
nums.reverse()               # 原地反转
sorted(nums)                 # 返回一个排好序的新列表，不改原列表
```

## 5.7 循环列表

```python
names = ['Alex', 'Jack', 'Rain']

for i in names:              # 最常用
    print(i)

for index, i in enumerate(names):    # 同时拿到索引和值
    print(index, i)
# 0 Alex
# 1 Jack
# 2 Rain
```

## 5.8 列表常用方法速查

| 方法 | 作用 |
| --- | --- |
| `append(x)` | 末尾添加 |
| `insert(i, x)` | 指定位置插入 |
| `extend(L)` | 合并另一个列表 |
| `remove(x)` | 按值删除 |
| `pop(i)` | 按位置删除并返回 |
| `index(x)` | 查索引 |
| `count(x)` | 统计次数 |
| `sort()` / `reverse()` | 排序 / 反转 |
| `len(L)` | 长度（内置函数） |

# 六、赋值、浅拷贝与深拷贝

## 6.1 赋值只是贴标签

```python
>>> a = [1, 2, 3]
>>> b = a            # b 和 a 指向同一个列表
>>> b.append(4)
>>> a
[1, 2, 3, 4]         # 改 b，a 也跟着变
```

直接赋值**不会复制数据**，只是同一个对象多了一个名字。

## 6.2 浅拷贝

```python
>>> a = [[1, 2], 3]
>>> b = a.copy()     # 浅拷贝：复制最外层
>>> b.append(4)
>>> a
[[1, 2], 3]          # 外层互不影响
>>> b[0][0] = 99
>>> a
[[99, 2], 3]         # 但内层的子列表还是共享的！
```

浅拷贝只复制最外层，里面嵌套的对象仍然共享。

## 6.3 深拷贝

```python
import copy
b = copy.deepcopy(a)   # 深拷贝：里里外外全部复制一份
```

深拷贝后两个对象彻底独立，改任何一个都不影响另一个。数据有嵌套、又需要完全独立时才用它。

# 七、字符串（str）进阶

字符串是**有序的字符集合**，用来表示文本。

```python
s = 'Hello, beauty! How are you?'
```

字符串两大特性：

1. **有序**：可以像列表一样用索引、切片（`s[0]`、`s[1:4]`）；
2. **不可变**：字符串本身不能修改。所有"修改"方法都是返回一个新字符串。

```python
>>> a = 'alex'
>>> id(a)
4315438360
>>> a = 'jack'      # 不是改掉 alex，而是指向了一块新内存
>>> id(a)
4315497000
```

## 7.1 常用方法（全部返回新字符串，不改原值）

**查找与统计**

```python
s = 'Hello world'
s.find('o')         # 查找，返回索引；找不到返回 -1
s.rfind('o')        # 从右边找
s.index('o')        # 同 find，但找不到会报错
s.count('o')        # 统计出现次数
s.startswith('He')  # 是否以...开头 → True
s.endswith('d')     # 是否以...结尾 → True
```

**大小写与格式**

```python
s.upper()           # 全大写 → 'HELLO WORLD'
s.lower()           # 全小写
s.swapcase()        # 大小写互换
s.title()           # 每个单词首字母大写
s.center(20, '*')   # 居中，两侧用 * 补齐
s.ljust(20, '-')    # 左对齐，右侧补 -
s.rjust(20, '-')    # 右对齐
s.zfill(20)         # 左侧补 0
```

**去除空白 / 替换**

```python
s = '  hello  '
s.strip()           # 去掉两端空格（也去 \n、\t）
s.lstrip()          # 只去左边
s.rstrip()          # 只去右边
s.replace('l', 'L')      # 替换
s.replace('l', 'L', 1)   # 只替换第 1 个
```

**切分与拼接**

```python
s = 'hello world python'
s.split()                # 按空格切成列表 → ['hello','world','python']
s.split('o')             # 按指定字符切
s.splitlines()           # 按换行符切
','.join(['a', 'b'])     # 列表拼成字符串 → 'a,b'
```

**判断类**（返回 True / False）

```python
'22'.isalnum()       # 是否全是字母或数字 → True
'abc'.isalpha()      # 是否全是字母
'33'.isdigit()       # 是否全是数字
'abc_1'.isidentifier()  # 是否是合法变量名
'abc'.islower()      # 是否全小写
'Hello World'.istitle()
'33'.isnumeric()
```

**格式化**

```python
'My name is {0}, I am {1}'.format('Alex', 22)
'{name}'.format(name='Alex')
```

（日常优先用 f-string，见第一章。）

**字符翻译（了解）**

```python
table = str.maketrans('abc', '123')
'abcabc'.translate(table)      # '123123'
```

最常用的 9 个：`isdigit`、`replace`、`find`、`count`、`strip`、`center`、`split`、`format`、`join`。

# 八、元组（tuple）

元组和列表几乎一样，也是一组有序数据，区别是**一旦创建就不能修改**，所以又叫"只读列表"。

```python
names = ('alex', 'jack', 'eric')
```

特性：

- 不可变：不能增、删、改；
- 但如果元组里放了一个可变元素（如列表），那个列表内部仍可修改：

```python
>>> t = (1, 2, ['a', 'b'])
>>> t[2][0] = 'A'
>>> t
(1, 2, ['A', 'b'])
```

功能只有查询：`index()`、`count()`、切片。

使用场景：

- 明确告诉别人"这里的数据不允许修改"，防止被误改；
- 存数据库连接配置等固定信息；
- 函数一次返回多个值时，Python 默认返回的就是元组。

> 定义只有一个元素的元组要加逗号：`(1,)`，否则 `(1)` 只是数字 1。

# 九、hash（哈希）

Hash（哈希/散列）：把任意长度的输入，通过算法变成一个**固定长度**的输出（哈希值）。

特点：

- 同样的输入，哈希值永远相同；
- 不同输入可能碰巧哈希到同一个值（哈希碰撞），所以**不能从哈希值反推出原内容**；
- 被哈希的值必须是**不可变**的。

```python
>>> hash('abc')
-4433113422783876225
>>> hash((1, 2, 3))       # 元组不可变，可以哈希
2528502973977326415
>>> hash([1, 2, 3])       # 列表可变，不能哈希
TypeError: unhashable type: 'list'
```

常见用途：文件签名、MD5/SHA 校验、密码验证、字典 key 的快速查找（第四章会学 hashlib）。

# 十、字典（dict）

**一个变量怎么存公司每个员工的完整信息？** 列表只能按位置取，字典可以**按名字（key）取**。

字典是 **key-value（键值对）** 结构，就像查字典：通过"键"快速找到对应的"值"。

```python
info = {
    'stu1101': 'TengLan Wu',
    'stu1102': 'LongZe Luola',
    'stu1103': 'Xiaoze Maliya',
}
```

特性：

- key-value 结构；
- **key 必须可哈希、不可变、且唯一**（通常用字符串）；
- value 可以是任意类型、可重复、可修改；
- 查找速度极快，且不受数据量影响；
- Python 3.7+ 字典保持插入顺序（早期版本无序）。

## 10.1 查询

```python
info['stu1101']            # key 不存在会报 KeyError
info.get('stu1199')        # 更安全：不存在返回 None
info.get('stu1199', 0)     # 不存在时返回指定的默认值 0
```

## 10.2 增加 / 修改

```python
info['stu1104'] = 'New Guy'     # key 不存在就是新增
info['stu1101'] = 'New Name'    # key 已存在就是修改
info.setdefault('stu1105', 'Tom')  # key 不存在才添加，已存在则不动
info.update({'a': 1, 'b': 2})   # 批量合并/更新
```

## 10.3 删除

```python
info.pop('stu1101')        # 按 key 删除并返回 value
del info['stu1102']       # 也可以用 del
info.popitem()             # 删除最后一个键值对
info.clear()               # 清空
```

## 10.4 循环字典

```python
info = {'a': 1, 'b': 2}

for key in info:                  # 默认遍历 key
    print(key, info[key])

for key, val in info.items():     # 最常用：同时取 key 和 value
    print(key, val)

info.keys()                       # 所有 key
info.values()                     # 所有 value
info.items()                      # 所有 (key, value) 对
```

字典也支持推导式：`{k: v for k, v in pairs}`。

# 十一、集合（set）

集合是一个**无序、不重复**的数据容器，主要用于**去重**和**关系运算**。

```python
iphone7 = {'alex', 'rain', 'jack', 'old_driver'}
iphone9 = {'alex', 'jack', 'shanshan', 'old_boy'}
```

去重是它最常见的用法：

```python
>>> list(set([1, 1, 2, 3, 3]))
[1, 2, 3]
```

## 11.1 关系运算

```python
# 交集：两边都买了的人
iphone7.intersection(iphone9)
iphone7 & iphone9                 # {'alex', 'jack'}

# 差集：只买了 iphone7 的人
iphone7.difference(iphone9)
iphone7 - iphone9                 # {'rain', 'old_driver'}
iphone9 - iphone7                 # {'shanshan', 'old_boy'}

# 并集：所有人（自动去重）
iphone7.union(iphone9)
iphone7 | iphone9

# 对称差集：只买了其中一种的人（并集去掉交集）
iphone7.symmetric_difference(iphone9)
iphone7 ^ iphone9
```

## 11.2 增加 / 删除 / 判断

```python
s = {1, 2, 3}
s.add(4)                  # 添加
s.remove(2)               # 删除（不存在会报错）
s.discard(2)              # 删除（不存在不报错，更安全）

s.issubset({1,2,3,4})     # s 是否被包含（<=）
s.issuperset({1})         # s 是否包含对方（>=）
s.isdisjoint({5})         # 是否完全不相交
1 in s                    # 元素是否在集合中
```

`frozenset` 是不可变版本的集合，可以被哈希：`frozenset({1, 2, 3})`。

> 集合里只能放不可变元素，不能放列表、字典。

# 十二、本章作业

**作业 1：购物车程序**
