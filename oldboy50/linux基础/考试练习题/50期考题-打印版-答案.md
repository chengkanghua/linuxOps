# 一、请详细描述linux系统从打开主机电源到进入登录界面整个过程的流程。

```bash
BIOS开机自检
mbr引导
grub菜单
加载内核 kernel
init进程
/etc/inittab
/etc/rc.d/rc.sysinit
/etc/re.d/rc
登录界面


1. 主机上电 + BIOS/UEFI 硬件自检 POST
按下电源键，主板通电：
主板固件 BIOS（传统）/UEFI（新式） 率先运行；
执行 POST 上电自检，依次检测 CPU、内存、显卡、硬盘、外设等硬件；
硬件无故障后，读取启动顺序，选择第一启动项（本地硬盘）。
2. 硬盘引导 + GRUB 引导器启动
传统 BIOS+MBR
读取硬盘第 1 个扇区 MBR（512B），执行主引导代码；
识别活动分区，加载分区引导记录，转而启动 GRUB 引导程序。
新式 UEFI+GPT
读取硬盘 ESP 隐藏分区 中的 EFI 引导文件；
直接加载 grubx64.efi，启动 GRUB。
GRUB 弹出内核选择菜单，等待选择 Linux 内核版本。
3. GRUB 加载内核与临时根文件系统
GRUB 将两个核心文件载入内存：
vmlinuz：Linux 内核镜像
initramfs：临时迷你根文件系统（含磁盘、文件系统硬件驱动）
4. 内核解压运行 + 硬件初始化
内核在内存中解压、自启动；
初始化核心子系统：内存管理、进程调度、中断管理、总线；
依靠 initramfs 里的驱动，识别硬盘、RAID、文件系统等硬件；
挂载真实根分区 /，用完后卸载 initramfs 临时文件系统。
5. 内核拉起系统一号进程
内核完成硬件初始化，从内核态切换到用户态，启动系统第一个用户进程：
现代 Linux（CentOS7+/Ubuntu16.04+）：systemd 进程，PID=1
老式 SysVinit：/sbin/init
6. Systemd 初始化系统服务
systemd 作为所有进程父进程，按配置依次执行：
挂载所有系统分区：/home、/var、/tmp 等；
加载硬件驱动、设置主机名、系统环境；
启动网络、日志、定时任务等系统守护进程；
切换到运行目标：
字符界面：multi-user.target
图形界面：graphical.target
7. 启动登录管理器，进入登录界面
图形界面：启动 GDM/LightDM/SDDM 登录管理器，弹出图形账号密码登录窗口；
字符界面：启动 getty 进程，弹出黑底白字的文本登录提示符。
8. 等待用户输入账号密码
停留在登录界面，等待用户输入用户名、密码，验证后进入系统桌面 / 命令行终端。

```

<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">新手最容易错的地方，</font><code>**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">*</font>**``**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">?</font>**``**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">.</font>**</code>**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);"> 在两者里意思完全不同</font>**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">！</font>

| **<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">符号</font>** | **<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">通配符（匹配文件名）</font>** | **<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">正则表达式（匹配文本内容）</font>** |

### <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">3 大核心区别（背诵版）</font>
