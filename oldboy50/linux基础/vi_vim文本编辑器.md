# vi / vim 文本编辑器

> 本文系统整理 Vim 的三大模式、打开/保存/退出、高频快捷键（移动/删除/搜索/替换/批量列编辑）、文件恢复（.swp）与个性化配置（分屏/语法高亮/配色）。

## 一、Vim 三大核心模式（必背）

Vim 所有操作都基于这 3 种模式，切换逻辑是核心。

| 模式名称 | 核心作用 | 进入 / 切换方式 |
| :--- | :--- | :--- |
| **命令模式**（默认） | 执行快捷键（复制、删除、跳转、搜索），**无法输入文字** | 1. 打开文件默认进入<br/>2. 编辑模式按 `ESC` 回到 |
| **输入模式**（编辑模式） | 正常输入、修改文本内容 | 命令模式按 `i` / `a` / `o` 等快捷键 |
| **底线模式**（末行模式） | 执行保存、退出、替换、显示行号等操作 | 命令模式按 `:`（冒号）进入 |

## 二、基础操作：打开 / 保存 / 退出（底线模式命令）

在**命令模式**下按 `:` 输入，执行后回车生效。

| 命令 | 功能说明 |
| :--- | :--- |
| `:w` | 仅保存文件 |
| `:w 文件名` | 另存为新文件 |
| `:q` | 退出 Vim（未修改时可用） |
| `:q!` | 强制退出，**不保存**修改 |
| `:wq` | 保存并退出 |
| `:x` | 保存并退出（简写，和 wq 功能一致） |

## 三、高频快捷键大全（命令模式下使用）

### 1. 快速进入输入模式（最常用）

| 快捷键 | 功能说明 |
| :--- | :--- |
| `i` | 在光标**左侧**插入（最常用） |
| `a` | 在光标**右侧**插入 |
| `I` | 在当前行**行首**插入 |
| `A` | 在当前行**行尾**插入 |
| `o` | 在当前行**下方**新建一行 |
| `O` | 在当前行**上方**新建一行 |
| `cc` | 删除整行并直接进入编辑模式 |
| `C` | 删除光标到行尾，并进入编辑模式 |

### 2. 光标移动（高效操作）

| 快捷键 | 功能说明 |
| :--- | :--- |
| `h`← `j`↓ `k`↑ `l`→ | 上下左右移动（替代方向键） |
| `gg` | 跳转到**文件第一行** |
| `G` | 跳转到**文件最后一行** |
| `nG` / `ngg` | 跳转到指定行（例：`10G` → 第 10 行） |
| `0` | 跳转到当前行**绝对行首** |
| `$` | 跳转到当前行**行尾** |

### 3. 删除 / 撤销 / 恢复

| 快捷键 | 功能说明 |
| :--- | :--- |
| `x` | 删除光标所在字符 |
| `dd` | 删除**当前整行** |
| `ndd` | 删除连续 n 行（例：`3dd` → 删除 3 行） |
| `dG` | 删除光标所在行 → 文件末尾 |
| `u` | 撤销上一步操作（必备） |
| `U` | 撤销对当前行的所有修改 |

### 4. 显示 / 隐藏行号

| 命令 | 功能说明 |
| :--- | :--- |
| `:set nu` | 显示行号 |
| `:set nonu` | 隐藏行号 |

### 5. 文本搜索

| 快捷键 | 功能说明 |
| :--- | :--- |
| `/关键词` | **向下**搜索关键词 |
| `?关键词` | **向上**搜索关键词 |
| `n` | 查找**下一个**匹配内容 |
| `N` | 查找**上一个**匹配内容 |
| `:noh` | 临时取消搜索高亮 |

### 6. 文本替换（底线命令）

| 命令 | 功能说明 |
| :--- | :--- |
| `:s/旧内容/新内容` | 替换当前行**第一个**匹配内容 |
| `:s/旧内容/新内容/g` | 替换当前行**所有**匹配内容 |
| `:n,ms/旧内容/新内容/g` | 替换 n~m 行的所有内容 |
| `:%s/旧内容/新内容/g` | 替换**整个文件**所有匹配内容 |

### 7. 批量列编辑（批量修改神器）

| 步骤 | 操作 |
| :--- | :--- |
| 1 | `Ctrl + v` 进入**列编辑模式**，选中目标区域 |
| 2 | 按 `I`（大写 i）进入编辑 |
| 3 | 输入要添加的内容 |
| 4 | 按 `ESC`，批量生效 |

### 8. 帮助文档

| 命令 | 功能说明 |
| :--- | :--- |
| `:help` | 打开 Vim 帮助文档 |
| `:help 快捷键` | 查看指定快捷键说明（例：`:help G`） |
| `:q` | 退出帮助文档 |

## 四、退出文件的恢复（.swp 文件）

异常退出会在当前文件夹下产生 `.swp` 的隐藏文件（交换文件），可用它恢复未保存的内容：

```bash
vim -r index.html.swp
```

## 五、Vim 个性化

```bash
# 编辑一个代码文件（代码长度越长越好，便于练习）
vim test.c

# 分屏
ctrl+w+v          # 屏幕一分为二（再按可分三）；长格式 :vsplit
:vsp              # 命令行模式下垂直分屏（长格式 :vsplit）
:sp               # 横屏（长格式 :split）

# 屏幕之间切换
ctrl+w+l          # 最后一个 l 是方向（l/h/k/j）

# 编辑方式和平常一样

# 在同一个窗口下打开多个不同的文件
:e <path_to_file>/filename.extension
:e ~/.vimrc
:sp <file_path>
:vsp <file_path>

# 开启语法高亮（写入 ~/.vimrc）
echo "syntax on" >> /root/.vimrc      # syntax off 是关闭

# 查看可用配色方案
ls /usr/share/vim/vim74/colors/
# blue.vim  darkblue.vim  default.vim  delek.vim  desert.vim  elflord.vim
# evening.vim  koehler.vim  morning.vim  murphy.vim  pablo.vim  peachpuff.vim
# README.txt  ron.vim  shine.vim  slate.vim  torte.vim  zellner.vim

# 临时更改配色方案
vim hello.html
:colorscheme morning

# 永久更改配色方案（写入 /root/.vimrc）
vim /root/.vimrc
syntax on
color evening
set background=dark
```
