# <font style="color:#C00000;">老男孩核心思想</font>：学习过程往往比结果更重要

> **学习要尽量重过程而非结果，只要学习方法是得当的，加上持久地练习，形成良好的学习习惯后，自然就有好的结果！**
>
> —— 老男孩

---

## 一、职场里听得最多的是"结果导向"

我们在工作中听得最多的可能就是"结果导向"一词：凡事都要问问自己想要什么结果，凡事要结果导向，要的是结果而不是过程，要的是有效果，而不是有道理。

在职场上，我们做事有时候确实会按照上面的原则去做。但是，在很多时候，往往**只有过程正确，结果才能正确**；并且随着时间的推移，结果仍是正确的。

## 二、过程正确，结果才会持续正确

做任何一件事情，只要过程是正确的，一般情况下，只要持续坚持对的过程，就一定会有好结果，并且结果会持续地更好 —— 也就是**发展空间更大、天花板更高**。

## 三、过早注重结果，动作必然变形

做一件事如果过早地注重结果，就一定会导致做事的行为和动作变形，最终导致结果不是预期的。

即使短时间可能没问题（达到了预期），但当**时空角拉长**，过若干较长的时间后，结果也必然会有问题。

> 短期靠运气和蛮力拿到的结果，长期一定会被错误的动作还回去。

## 四、案例一：台球 —— 动作定型后再改，要花十倍精力

学打台球、打羽毛球等运动，就是典型的"过程比结果更重要"的事情（其他事情也是一样的）。

如果只想进球，不注意过程中的动作是否对（是否科学），例如：

- 占位姿势
- 握杆
- 架杆
- 瞄准
- 运杆
- 发力

这一系列过程是不是正确的，即使当下球打进了，得到了暂时的快感，但是由于动作不对，还依旧持续错误的动作和行为，会让自己形成**错误的潜意识和肌肉记忆**，最终离通向高手之路越来越远。

因为动作长期变形（不科学），并且习惯了自己这样的行为动作，以后就极难改正到正确的动作（可能要花 **10 倍**的精力），提升和成长也会大大受限。

> 老男孩当初问过北京市昌平区的台球冠军：为什么不走专业运动员路线？
>
> 得到的回答是：很多击球的行为动作和思维已经定型，但并不是最科学的，因此后期提升很难达到顶尖水平，所以就没走专业运动员的发展路线。
>
> 可见**过程正确**对结果（特别是更好的结果）的影响有多大。如果只是随便玩玩，那就都无所谓了。

## 五、案例二：羽毛球 —— 每一个细节都是过程

打羽毛球何尝不是如此。从开始的握拍，双手大臂、小臂、肩肘的动作，脚下步伐，击球点和角度，击球后的随前动作，以及双脚落地姿势、下一个跑位，都会影响一个球员的打球水平，**而不仅仅是把球打过网就得了**。

## 六、核心方法论：过程正确 + 持续练习 = 肌肉记忆

> <font style="color:#C00000;">**只有过程是对的，再加上不断地练习，将行为形成潜意识（不经过大脑思考）的习惯（即肌肉记忆），才会在任何时间和地点，一出手就是专业和规范的，高薪也会唾手而得！**</font>

对于绝大多数人来说，选择系统地参加老男孩 IT 培训，是提升自己的最佳途径，并且后期的发展也是最快的，没有之一 —— 因为老男孩不但会教你知识，更会教你**学习方法**，培养你**正确的学习思维**和**职场做人做事的习惯**。

> —— 老男孩老师

## 总结（核心记忆点）

1. **一句话核心**：学习要重过程而非结果；方法得当 + 持久练习 + 良好习惯 = 自然会有好结果。
2. **过程与结果的关系**：过程正确 → 结果正确；且时间越长，结果越好、天花板越高。
3. **过早盯结果的代价**：行为和动作变形 → 短期看似达标，长期必然出问题。
4. **反面案例（台球 / 羽毛球）**：只求"进球""过网"而不求动作科学 → 形成错误的肌肉记忆 → 后期改正要花十倍精力 → 永远到不了顶尖。
5. **正确的成长路径**：规范动作 → 反复练习 → 形成潜意识（肌肉记忆）→ 任何时间、任何地点一出手就专业规范 → 高薪唾手而得。
6. **系统学习的价值**：不仅学知识，更要学**方法**、练**思维**、养**习惯** —— 这三者才是决定上限的东西。

> 记住：**结果是过程的副产品**。盯着过程打磨，结果会自己跑来；盯着结果硬凑，过程一定会烂掉。

## 扩展

### 扩展一：这与"刻意练习"理论不谋而合

心理学家安德斯·艾利克森（Anders Ericsson）在《刻意练习》中提出：决定水平的不是**练习时长**，而是**练习质量**。刻意练习的四个特征，和老男孩这段话几乎一一对应：

| 刻意练习的特征 | 本文的对应说法 |
| --- | --- |
| 有明确定义的特定目标 | 握杆、架杆、瞄准……每一步都有标准 |
| 专注的练习状态 | 重过程，不走神、不糊弄 |
| 即时的反馈与纠正 | 动作是否"科学"，错了立刻改 |
| 走出舒适区 | 持久地练习、改掉定型动作要花十倍精力 |

反之，"只求把球打进"就是典型的**天真练习**（naive practice）—— 重复一万次错误的动作，只会让错误更牢固。

### 扩展二：技能习得的四个阶段

任何技能（打球、敲命令、排故障）都要经历这四个阶段：

1. **无意识无能**：不知道自己不会（以为把球打过网就不错了）；
2. **有意识无能**：知道自己不会，开始学标准动作（需要刻意想着做）；
3. **有意识胜任**：做对了，但还得想着才能做对；
4. **无意识胜任**：不用想就能做对 —— 这就是老男孩说的**潜意识 / 肌肉记忆**。

绝大多数人卡在第 2 阶段就放弃了，或者停留在第 3 阶段再也不精进。**只有走到第 4 阶段，才叫"专业"。**

### 扩展三：放到 Linux 运维学习上，具体怎么做

把"重过程"翻译成运维学习的日常动作：

- **命令不要死记，要标准地敲**：先理解 `man` 里每个参数的含义，再反复敲到形成肌肉记忆，而不是复制粘贴跑通就完事；
- **排错要讲方法论，不要瞎试**：先定位（看日志、看状态、看监控）→ 再假设 → 再验证，而不是百度到一条命令就乱执行；
- **环境要规范**：目录结构、命名规则、配置文件注释、变更留痕，这些"过程动作"决定了你能不能进大厂；
- **每学一个知识点就输出**：写笔记、画思维导图、讲给同学听 —— **输出才是最好的输入**；
- **刻意做"不舒服"的练习**：手敲 Nginx 配置而不是 copy；手写 awk/sed 而不是找脚本；自己搭一遍集群而不是只看视频。

一句话：**别只追求"服务跑起来了"，要追求"我用的是最规范的那套姿势让它跑起来的"。**

### 扩展四：过程导向 ≠ 不要结果

这两者并不矛盾，正确的用法是**分工**：

- **用结果做方向的校准**：目标（想成为什么样的工程师、拿多少薪资）用来定方向，定期检查，防止南辕北辙；
- **用过程做日常的执行**：每天的注意力放在"今天的动作标不标准"上，而不是"今天有没有立刻见效"。

即：**长期看结果，短期看过程。** 天天盯 KPI 的人动作会变形；完全不看方向的人会原地打转。两者结合才是正解。

### 扩展五：警惕"伪勤奋"

"重过程"很容易被误解成"只要我够努力就行"，于是出现三种典型的伪勤奋：

1. **堆时长**：学了 10 小时，但全程在看视频、抄代码，没有一次独立思考；
2. **抄结果**：实验做通了，但每一步为什么这么做说不出来；
3. **不纠错**：同一个错误反复犯，因为从来没复盘过。

**区分标准很简单：你的动作是不是"科学的、可复现的、能讲清楚的"。** 如果不是，那只是用战术上的勤奋，掩盖战略上的懒惰。

### 扩展六：给自己搭一个"过程闭环"

建议养成下面这个闭环，把"重过程"真正落地（可与本目录下 `oldboy思想分析.md` 的"看、听、想、写、做、讲"七步法对照学习）：

```
看一遍 → 听一遍 → 想一遍 → 写一遍（笔记/脑图） → 做一遍（实操） → 讲一遍（输出）
                                                        ↑                    |
                                                        └──── 复盘纠错 ──────┘
```

每循环一次，动作就更规范一分；循环足够多次，专业就是本能。
