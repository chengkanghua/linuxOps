# 曾老湿带你轻松过面试-HR篇

【HR篇】：

HR常见问题：

问题1：请做一下自我介绍？

问题2：你为什么要离职？

问题3：你找工作时，最重要的考虑因素是什么？

问题4：你的家住哪里？

问题5：你的期望薪资是多少？

问题6：你有没有女朋友？

问题7：你对加班怎么看？

问题8：你的职业规划是什么？

问题9：你对我们公司了解有多少？

问题10：我们为什么要录用你？

 

**HR常见问题分析及思路：**

 

**问题1：请做一下自我介绍？**

**分析：**

HR心里，让你做自我介绍，主要是想看看你的语言表达能力，以及你个人的心里素质，还有就是是否与简历中写的相符。

**回答思路：**

+ 1.这是面试的必考题目。
+ 2.介绍内容要与个人简历相一致（个人信息，学历，年龄）。
+ 3.表述方式上尽量口语化。
+ 4.要切中要害，不谈无关、无用的内容。
+ 5.条理要清晰，层次要分明。
+ 6.事先最好以文字的形式写好背熟（尽量按自己理解，不要死记硬背）。

 

**问题2：你为什么要离职？**

**分析：**

HR问这个问题时，主要想看看你是一个什么样的人，是因为工作能力不足？还是做人态度不够？（被辞退......）还是你根本就不是一个安分的人？一心只想要更高的工资？

**错误回答：**

+ 1.因为上家公司同事不太友好，相处不了（气场不合）。
+ 2.因为上家公司，给的薪资不到位。
+ 3.我觉得我会的太多了，那家公司技术水平已经容不下我这尊大佛。
+ 4.因为上家公司平台不好，我想要更大的平台。
+ 5.因为上家公司黄了。
+ 6.因为我不想在那家公司干了，不感兴趣
+ 7.因为天天都要加班到很晚，身体扛不住。

**HR：......... What The Fuck?**

**一首凉凉送给你，凉凉夜色为你............落地成盒。**

**回答思路：**

+ 1.首先夸一下你的上一家公司的上司（你是一个懂得感恩的人）
+ 2.你在离职时，上司也挽留过你很多次（你是一个工作能力很强的人）
+ 3.此时再说你的离职原因，例：  
公司的平台基本稳定，后续也不会有更大的改变（不是你不想留，而是公司平台限制，不是你的个人原因）  
我还年轻，在一个学习的阶段，我想要学习更多的知识来充实自己（你是一个上进好学的人）
+ 4.一定要避免HR抓住你任何把柄，从而打压你的薪资，甚至不想录用你。

 

**问题3：你找工作时，最重要的考虑因素是什么？**

**分析：**

HR在问这个问题的时候，就是要看看你，是不是因为薪资的不满足，如果薪资不满足，公司为什么不给你涨薪？难道是你能力不够？**公司要找的是工作表现好、能够真正有贡献的人，而非纯粹慕名、求利而来的人。**

**错误回答：**

+ 1.我觉得是能让我满意的一个薪资。
+ 2.我觉得是符合我技术水平的一个薪资。
+ 3.我想要更大的一个平台。
+ 4.我想去一个人好的公司。

**回答思路：**

+ 1.首先我觉得公司最重要的就是团队，有一个好的团队，不管是工作效率还是工作的气氛，融洽度都会有所提升，这样的工作环境不仅对我们个人都有好处，对公司的利益更加有好处。
+ 2.其次，我看重的是，工作性质，是否可以让我发挥所长，并且能让我不断的成长。

 

**问题4：你家住哪里？**

**分析：**

HR在问这个问题的时候，主要是看你住的离公司是否很近？如果很近，公司出了问题，是否可以快速的到达公司处理问题？如果很远，你是否可以考虑搬家？

**错误回答：**

+ 1.我住在xxx（离的很远）
+ 2.我想找个离家近点的公司。

**回答思路：**

+ 1.如果家离的很近，那就直接回答，我家在xxx，我可以保证7*24小时，出了问题，随时来公司处理问题。
+ 2.如果家离的很远，我家住在xxx，离的很远，不过我是单身，可以随时搬家，我搬家很方便，只要公司有需求，我可以随时搬到公司的附近。

 

**问题5：你期望的薪资是多少？**

**分析：**

HR在问这个问题的时候，首先内心是想打压你的工资的，其次，看看你是不是符合这个薪资，最后看你，是不是贪图利益，如果是因为薪资不到位，你是不是之前说的那些，想要学习，让自己能够得到更好的发展相冲突？

**错误回答：**

+ 1.如果是电话面试：面议
+ 2.如果是现场面试：1万左右吧
+ 3.如果是现场面试：1万-1万5吧

**回答思路：**

+ 1.一定要说一个确切的数值。
+ 2.要把上家公司的薪资说出来，当然，上家公司的薪资，也不一定说的是真的，要比期望高。（让别人认为你并不是为了利益，那种不满足的人，期望特别高）
+ 3.要薪资的时候一定要有自信（我觉得，我就值这个钱，你们买不了吃亏，买不了上当）
+ 4.要表述的很谦虚，你就是为了学习并不是为了薪资。
+ 5.一定要说的，比自己期望的薪资要多出来几千（因为HR会压工资）。

 

**问题6：你有没有女朋友？**

**分析：**

HR在问这个问题的时候，就是想知道，你是不是自由的，你会不会因为情感的事，影响到你的工作，甚至影响到你工作的效率，还有就是，你能不能放弃你的黄金时间，去给公司做贡献？

**错误回答：**

+ 1.像我这么帅的，能没有么？
+ 2.有啊，必须有。
+ 3.你觉得我像是没有对象的人么？

**回答思路：**

+ 1.不管你有没有，一定都要说没有。
- 1）第一是为了告诉HR，你自由，你随时为企业奉献自己
- 2）第二如果你长的帅，还能给别人留点念想，没准人家就录用你了。

 

**问题7：你对加班怎么看？**

**分析：**

HR在问这个问题的时候，是想知道，你到底可不可以来加班，她期望的就是，你可以来加班，并且，毫无理由的随时来加班，甚至能为企业做贡献，为公司谋利益。

**错误回答：**

+ 1.我上家公司，就是因为加班太多我就离职了。
+ 2.根本不想加班，太累了，身体扛不住啊。
+ 3.回答的很无所为，加不加班都行，可以加也可以不加。

**回答思路：**

+ 1.现在哪有IT公司不加班的，如果不加班，我反而觉得不太正常，估计公司的收益也不是很好。（体现加班是家常便饭，你可以接受加班）
+ 2.但是有些公司，说白了我之前公司，有些人完全是为了调休，为了加班费而加班，不仅不能给企业带来利益，反而还会给公司造成损失。
+ 3.所以我觉得加班，一定不要做无用功，好钢用在刀刃上，一定要加的有价值，为公司谋得更多的利益。

 

**问题8：你的职业规划是什么？**

**分析：**

HR在问这个问题的时候，就是想知道，你有没有规划，你是不是一个能够独立思考的人，最最最最最最最主要的就是......你能在公司干多久，能不能长期为公司效力，公司最讨厌的就是，来干了几个月就走了，跳槽频繁的人。

**错误回答:**

+ 1.我没有什么规划。
+ 2.随便说，说的很随意。
+ 3.我的规划是，以后要做个总监，做个CTO，做个CEO...

**回答思路：**

+ 1.首先要强调，我希望在公司稳定，沉淀自己。
+ 2.其次谦虚回答，我现在还年轻，我觉得我最重要的是充实自己，提升自己，不管是提升技术，提升智商，提升情商，提升格局，都是学习的机会。
+ 3.如果在我技术水平，这些都达到一定程度的时候，我希望，我的发展方向是（DBA，运维开发，管理层...）

 

**问题9：你对我们公司了解有多少？**

**分析：**

HR在问这个问题的时候，就是想看看你，是不是一个细心，做了充分准备，是不是真的想来我们公司来入职，还是只是为了面试而面试，敷衍一波。

**错误回答：**

+ 1.emmmmmm...没有了解。
+ 2.了解了那么一点点。
+ 3.简单的了解了一下。
+ 4.很了解。

**回答思路：**

+ 1.我在来贵公司面试之前，看了一下贵公司的官网，了解了一下贵公司的业务。
+ 2.贵公司主要是做xxx，涉及到哪些方面的业务。
+ 3.我对贵公司的业务方向，很感兴趣。
+ 4.我以前也是做这一方面的，对这些技术也有一定的了解。
+ 5.不知道我了解的是否足够，还劳烦您，能简单再给我介绍一下，我很愿意了解咱们公司的业务。

（让HR觉得，你对公司很感兴趣，想来公司发展，如果你有兴趣，那么你一定会在公司长留）

 

**问题10：我们为什么要录用你？**

**分析：**

HR在问这个问题的时候，就是想看看你，有什么能力，过人之处，芸芸众生为什么偏偏就要录用你来这个公司，你要有一个能说服她的理由，让她觉得录用了你，是可以给公司带来价值的。

**错误回答：**

+ 1.因为我深信我比别人优秀。
+ 2.因为我有很强烈的企图心，想要与贵公司共同成长。
+ 3.我在这个圈子里已经混了好几年了，我就是想扩张我的人脉。
+ 4.我也不知道为啥，emmmmm...

**回答思路：**

+ 1.你如何能让对方看到你的好?单凭口才，是很难以令人信服的。
+ 2.从履历，从人品，从态度，看出一切。
+ 3.体现自己的特长。
+ 4.体现自己的价值。
+ 5.体现自己能给公司带来的利益。
