# 拆分成多服务器架构

> 目标：把单机 LNMP 拆成「Web + 独立数据库 + 独立存储」，缓解单台压力，为后续集群化打基础。

## 一、整体拆分思路（7 步走）

1. 准备一台新服务器（克隆后改地址为 `172.16.1.51`）。
2. 安装 MySQL 数据库。
3. 备份原数据库数据。
4. 拷贝原数据库到新服务器。
5. 将数据导入新服务器。
6. 数据库允许远程连接。
7. 修改程序连接数据库的配置文件。

---

## 二、拆分 LNMP 数据库到独立服务器

### 第 1 步：老服务器导出并传数据
```bash
# 1. 导出全部数据库（Ckh123.com 是数据库密码）
mysqldump -uroot -p'Ckh123.com' --all-databases --single-transaction > `date +%F%H`-mysql-all.sql

# 2. 传到新服务器
scp `date +%F%H`-mysql-all.sql root@172.16.1.51:~
```

### 第 2 步：新服务器安装并导入 MySQL
```bash
# 1. 下载 MySQL 官方扩展源
rpm -ivh http://repo.mysql.com/mysql57-community-release-el7-11.noarch.rpm
# 其他可用地址：
# http://repo.mysql.com/mysql57-community-release-el7-8.noarch.rpm
# http://dev.mysql.com/get/mysql57-community-release-el7-10.noarch.rpm
# https://repo.mysql.com//mysql84-community-release-el7-1.noarch.rpm

# 关闭 gpg 检查（避免下载报密钥错误）
sed -i 's/gpgcheck=1/gpgcheck=0/g' /etc/yum.repos.d/mysql-community.repo
yum clean all && yum makecache

# 2. 安装 MySQL 5.7（文件较大，可能较慢）
yum install mysql-community-server -y

# 3. 启动并加入开机自启
systemctl start mysqld
systemctl enable mysqld

# 4. 5.7 默认生成临时密码，过滤查看
grep 'temporary password' /var/log/mysqld.log
mysql -uroot -p$(awk '/temporary password/{print $NF}' /var/log/mysqld.log)

# 5. 修改 root 密码
mysql> ALTER USER 'root'@'localhost' IDENTIFIED BY 'Ckh123.com';

# ----------------------------------------------------------------
# 6. 导入数据库
[root@db01 ~]# mysql -uroot -p'Ckh123.com' < 2018-08-0909-mysql-all.sql

# 7. 登录检查是否导入成功
[root@db01 ~]# mysql -uroot -pCkh123.com
mysql> show databases;
```

### 第 3 步：允许远程连接（授权）
```sql
-- 授权 root 从任意地址(%)连接，拥有全部权限
grant all privileges on *.* to 'root'@'%' identified by 'Ckh123.com';

-- 参数拆解
grant all privileges   授权所有权限
*.*                    授权所有库.所有表
'root'@'%'             被授权的用户及来源网段（% 表示任意）
identified by          该用户的密码
```

其他机器测试远程连接（先装 MySQL 客户端）：
```bash
yum provides mysql
yum install mariadb -y
mysql -h172.16.1.51 -uroot -pCkh123.com
```

### 第 4 步：修改程序连接信息
```bash
# WordPress：/code/wordpress/wp-config.php
define('DB_NAME', 'wordpress');
define('DB_USER', 'root');
define('DB_PASSWORD', 'Ckh123.com');
define('DB_HOST', '172.16.1.51');   # 改成独立数据库 IP

# EduSoho：/code/edusoho/app/config/parameters.yml
parameters:
  database_driver: pdo_mysql
  database_host: 172.16.1.51
  database_port: 3306
  database_name: edusoho
  database_user: root
  database_password: 'Ckh123.com'
  # 注意：修改后需清除缓存  rm -rf /code/edusoho/app/cache/*

# WeCenter：/code/zh/system/config/database.php
```

## 三、迁移图片至独立存储服务器（NFS）

### 1. NFS 服务端（nfs01, 172.16.1.31）操作
```bash
# 准备 www 用户（id 保持一致，避免权限错乱）
groupadd -g666 www
useradd -u666 -g666 www -s /sbin/nologin
yum install nfs-utils -y

# 配置共享目录
cat > /etc/exports <<EOF
/data           172.16.1.0/24(rw,sync,all_squash,anonuid=666,anongid=666)
/data/blog      172.16.1.0/24(rw,sync,all_squash,anonuid=666,anongid=666)
/data/edu/video 172.16.1.0/24(rw,sync,all_squash,anonuid=666,anongid=666)
/data/edu/files 172.16.1.0/24(rw,sync,all_squash,anonuid=666,anongid=666)
/data/zh        172.16.1.0/24(rw,sync,all_squash,anonuid=666,anongid=666)
EOF

# 创建目录并赋权
mkdir -p /data/{blog,edu/{video,files},zh}
chown -R www.www /data/
systemctl restart nfs-server
```

### 2. Web 端（web01）挂载并恢复数据

**WordPress（blog）**
```bash
yum install nfs-utils -y
# 查看可挂载的目录
showmount -e 172.16.1.31
# Export list for 172.16.1.31:
# /data/zh        172.16.1.0/24
# /data/edu/files 172.16.1.0/24
# /data/edu/video 172.16.1.0/24
# /data/blog      172.16.1.0/24
# /data           172.16.1.0/24

cd /code/wordpress/
cp -rp wp-content/ wordpress_back          # 先备份
mount -t nfs 172.16.1.31:/data/blog /code/wordpress/wp-content/
mv wordpress_back/* ./wp-content/          # 恢复原有图片/附件
echo "172.16.1.31:/data/blog /code/wordpress/wp-content/ nfs defaults 0 0" >> /etc/fstab
mount -a
```

**EduSoho（edu）**
```bash
# 找附件/图片路径：浏览器→右键→检查→Network→点图片
# 视频：/code/edusoho/app/data/udisk/   图片：/code/edusoho/web/files/
cp -rp /code/edusoho/web/files/ /code/edusoho/web/files_bak
cp -rp /code/edusoho/app/data/ /code/edusoho/app/data_bak

mount -t nfs 172.16.1.31:/data/edu/video /code/edusoho/app/data
mount -t nfs 172.16.1.31:/data/edu/files /code/edusoho/web/files

\cp -rp /code/edusoho/app/data_bak/* /code/edusoho/app/data/
\cp -rp /code/edusoho/web/files_bak/* /code/edusoho/web/files/

echo "172.16.1.31:/data/edu/video /code/edusoho/app/data nfs defaults 0 0" >> /etc/fstab
echo "172.16.1.31:/data/edu/files /code/edusoho/web/files nfs defaults 0 0" >> /etc/fstab
mount -a
```

**WeCenter（zh）**
```bash
cp /code/zh/uploads/ /code/zh/uploads_bak -rp
mount -t nfs 172.16.1.31:/data/zh /code/zh/uploads
cp /code/zh/uploads_bak/* /code/zh/uploads/ -rp
echo "10.0.0.5:/data/zh /code/zh/uploads nfs defaults 0 0" >> /etc/fstab
mount -a
```

## 四、快速扩容一台相同 Web 服务器（web02）

> 目标：数据库、图片、附件完全一致，新增 web02（10.0.0.8）直接加入集群。

```bash
# 1. 准备服务器，创建 www 用户
groupadd -g 666 www
useradd -u666 -g666 www -s /sbin/nologin

# 2. 安装 LNP（Nginx + PHP7.3）
cat > /etc/yum.repos.d/nginx.repo <<EOF
[nginx]
name=nginx repo
baseurl=http://nginx.org/packages/centos/7/x86_64/
gpgcheck=0
enabled=1
EOF
yum install nginx -y
systemctl start nginx && systemctl enable nginx

yum install -y http://rpms.remirepo.net/enterprise/remi-release-7.rpm
yum -y install yum-utils epel-release
yum install -y php73-php-fpm php73-php-cli php73-php-bcmath php73-php-gd \
  php73-php-json php73-php-mbstring php73-php-mcrypt php73-php-mysqlnd \
  php73-php-opcache php73-php-pdo php73-php-pecl-crypto php73-php-pecl-mcrypt \
  php73-php-pecl-geoip php73-php-recode php73-php-snmp php73-php-soap php73-php-xml

# 处理 CGI 路径解析问题 & 改运行用户
sed -i 's/;cgi.fix_pathinfo=1/cgi.fix_pathinfo=0/' /etc/opt/remi/php73/php.ini
sed -i '/^user/c user = www' /etc/opt/remi/php73/php-fpm.d/www.conf
sed -i '/^group/c group = www' /etc/opt/remi/php73/php-fpm.d/www.conf
systemctl restart php73-php-fpm && systemctl enable php73-php-fpm

# 3-4. 同步 nginx / php 配置
scp -rp root@172.16.1.7:/etc/nginx/* /etc/nginx/
scp -rp root@172.16.1.7:/etc/opt/remi/php73/php-fpm.d/* /etc/opt/remi/php73/php-fpm.d/
scp -rp root@172.16.1.7:/etc/opt/remi/php73/php.ini /etc/opt/remi/php73/
systemctl restart php73-php-fpm nginx
systemctl enable nginx php73-php-fpm

# 5. 同步站点代码
cd /code && tar zcvf code.tar.gz edusoho wordpress zh   # web01 上打包
mkdir -p /code && cd /code
scp root@172.16.1.7:/code/code.tar.gz ./               # web02 拉取
tar zxvf code.tar.gz

# 6. 同步挂载并挂载
scp root@172.16.1.7:/etc/fstab /etc/
mount -a
```

## 五、常见面试题

1. **为什么要做数据库与应用分离？**
   单机时数据库和应用抢资源，扩容受限；分离后可独立扩容、专人优化数据库，且为读写分离/主从复制打基础。

2. **MySQL 5.7 安装后首次登录密码在哪？**
   在 `/var/log/mysqld.log` 中过滤 `temporary password` 关键字。

3. **`grant all on *.* to 'root'@'%'` 各部分含义？**
   `all` 所有权限；`*.*` 所有库所有表；`'root'@'%'` 用户 root 可从任意地址连接；`%` 是来源通配符。

4. **NFS 的 `all_squash,anonuid=666,anongid=666` 有什么用？**
   把所有客户端访问用户统一映射为 uid/gid 666 的匿名用户，配合服务端 www(uid=666) 保证读写权限一致，避免权限错乱。

5. **Web 扩容为什么要求 www 用户的 uid/gid 保持一致？**
   代码和 NFS 共享都按 uid/gid 判权限。多台 Web 的 www 用户 uid/gid 不同会导致文件属主对不上，出现权限拒绝。

6. **新增一台 Web 节点，核心同步哪几类东西？**
   ① Nginx/PHP 配置；② 站点代码；③ 挂载信息（fstab 里的 NFS 挂载）；保证和已有节点完全一致。
