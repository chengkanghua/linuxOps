## nginx 负载均衡TCP配置(四层端口转发)

四层代理仅能存在main 段

```bash
# cat /etc/nginx/nginx.conf
#events下面 在http层上面, 
include  /etc/nginx/conf.c/*.conf;

mkdir -p /etc/nginx/conf.c
# cat /etc/nginx/conf.c/tream.conf
stream {
  #1.定义虚拟资源池
  upstream ssh {
    server 172.16.1.7:22;
  }
  upstream mysql {
    server 172.16.1.51:3306;
  }
  #2.调用虚拟资源池
  server {
    # 监听5555端口 当有人访问时候转到 ssh 虚拟池主机
    listen 5555;
    proxy_pass ssh;
  }
  server {
    listen 6666;
    proxy_pass mysql;
  }
}

nginx -t
systemctl restart nginx
netstat -lntp

# xshell 本地shell
[e:\~]$ ssh 10.0.0.5 5555
实际连接是连接上的是172.16.1.7 web01主机
windows 连接数据库工具 Navicat   连接lb02-5 主机6666端口


```

## Nginx动静分离

动静分离,通过中间件将动态请求和静态请求进行分离, 分离资源, 减少不必要的请求消耗, 减少请求延时。 好处: 动静分离后, 即使动态服务不可用, 但静态资源不会受到影响

# <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">Session 和Cookie</font>

## <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">一、一句话大白话定义</font>

1. **<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">Cookie</font>**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">：</font>**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">浏览器（客户端）</font>**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);"> 上存的一小段文本数据（键值对）</font>
2. **<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">Session</font>**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">：</font>**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">服务器</font>**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);"> 上存的用户数据（文件 / 内存 / Redis）</font>

***

## <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">二、核心区别（生产 / 面试必背表格）</font>

<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">表格</font>

| **<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">对比项</font>** | **<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">Cookie</font>** | **<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">Session</font>** |
| :--- | :--- | :--- |
| **<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">存储位置</font>** | <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">客户端（浏览器本地）</font> | <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">服务器端（内存 / 文件 / Redis）</font> |
| **<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">存储大小</font>** | <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">很小（单个≤4KB，一个站点最多 20 个）</font> | <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">几乎无限制（存用户信息、登录状态）</font> |
| **<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">安全性</font>** | <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">低（明文 / 可篡改、可见）</font> | <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">高（服务器存储，用户无法直接修改）</font> |
| **<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">生命周期</font>** | <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">可长期保存（设置过期时间）</font> | <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">默认浏览器关闭就失效</font> |
| **<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">性能压力</font>** | <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">无服务器压力</font> | <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">大量用户会占用服务器资源</font> |
| **<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">依赖关系</font>** | <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">独立存在，不依赖 Session</font> | **<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">必须依赖 Cookie</font>**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">（传递 Session ID）</font> |
| **<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">适用数据</font>** | <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">非敏感数据（记住账号、主题、购物车）</font> | <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">敏感数据（登录状态、用户信息、权限）</font> |

## <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">三、工作流程（Nginx+PHP 场景）</font>

<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">这是</font>**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">登录验证</font>**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">的标准流程，一看就懂：</font>

1. <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">用户第一次访问网站，</font>**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">服务器创建 Session</font>**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">，生成唯一的 </font><code><font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">Session ID</font></code>
2. <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">服务器把 </font><code><font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">Session ID</font></code><font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);"> 写入 </font>**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">Cookie</font>**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">，下发给浏览器</font>
3. <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">浏览器自动保存这个 Cookie（只存 Session ID）</font>
4. <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">用户后续每次请求，浏览器</font>**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">自动把 Cookie 带给服务器</font>**
5. <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">服务器通过 Cookie 里的 </font><code><font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">Session ID</font></code><font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">，找到对应的用户 Session 数据</font>

***

## <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">四、最关键的联系（90% 新手不懂）</font>

<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">👉</font><font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);"> </font>**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">Session 本身不能传输，必须靠 Cookie 带 Session ID</font>**

* <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">Cookie 存的是：</font><code><font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">PHPSESSID=abc123</font></code><font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">（一串随机码）</font>
* <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">Session 存的是：</font><code><font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">{"username":"admin","login":true}</font></code><font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">（真实用户数据）</font>

***

## <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">五、生产高频问题</font>

### <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">1. 禁用浏览器 Cookie 会怎样？</font>

<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">Session 直接失效（因为无法传递 Session ID），需要用 </font>**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">URL 重写</font>**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);"> 兼容（很少用）。</font>

### <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">2. Nginx 集群 / 多服务器时，Session 怎么办？</font>

<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">默认 Session 存在单台服务器，切换机器会掉线</font>**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">解决方案</font>**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">：用 </font>**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">Redis 统一存储 Session</font>**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">（生产标准）。</font>

### <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">3. 为什么登录状态用 Session，不用 Cookie？</font>

<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">Cookie 能被用户篡改，比如把 </font><code><font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">login=false</font></code><font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);"> 改成 </font><code><font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">true</font></code><font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);"> 直接越权；Session 在服务器，用户无法修改，</font>**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">安全</font>**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">。</font>
